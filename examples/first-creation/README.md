# GardenFlow 首次创作示例

配合[首次创作教程](../../Docs/FIRST_CREATION.md)使用。

- [公开输入资料](./sources/gardenflow-facts.md)：可导入知识库，附原始来源和能力边界。
- [分步提示词](./prompts.md)：选题、写作、人工审阅后保存、可选封面。
- [人工核对后的介绍稿](./output/gardenflow-intro.md)：由实际模型输出整理，保留可打开的来源。
- [实际生成的 3:4 封面](./output/gardenflow-first-creation-cover.png)：由 GardenFlow 保存到媒体库后复制到案例目录。
- [演示与实际验证记录](../../Docs/DEMO.md)：区分实测结果和待验证环节。

同样的输入和提示词不保证得到相同输出。模型、参数、上下文和人工编辑都会影响结果。只有实际运行、检查并保存的稿件或封面才会登记为演示产物。

本次人工修改删除了 QA 环境路径和草稿状态，统一“文本模型”称呼，并把重复段落压缩为公开案例。没有补写输入资料未提供的产品能力、用户数量或效率数据。
