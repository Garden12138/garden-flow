# 首次创作提示词

先在创作输入区附加[公开资料](./sources/gardenflow-facts.md)，再逐段使用下面的提示词。

## 选题

```text
根据我附加的 GardenFlow 公开资料，给中文 AI 内容创作者提出 3 个介绍角度。
每个角度包括：标题、要解决的具体问题、读者能得到什么、支持该角度的来源。
优先考虑“把收集的资料变成有来源的稿件”，不要编造用户数量、效率数据或我的个人经历。
先给候选，等我选定后再写正文。
```

## 选择

```text
选择“从资料到一篇有来源的介绍稿”这个角度。
请继续使用已附加资料，不引入未提供的产品能力。
```

## 成稿

```text
请写一篇 600～900 字的 GardenFlow 中文介绍稿，面向中文 AI 内容创作者。
结构：资料散落的具体问题 → GardenFlow 的资料、选题、稿件与封面流程 → 如何开始 → 当前限制。
事实陈述附上资料中可打开的原始链接，不用无法定位的虚构引用。
明确说明：用户自行配置模型；图片服务单独配置；项目采用非商业 Source-Available 许可证；使用外部模型会把相关输入发送给所选供应商。
不要写“我已经生成了封面”“只花 20 秒”“完全离线”或未验证的体验。
先输出正文供我审阅，收到确认后再保存为稿件，不发布到任何平台。
```

## 审阅后保存

```text
请按我刚才的修改保存最终稿件，标题为“从资料到稿件：GardenFlow 首次创作”。
保存后告诉我如何在稿件页打开它。只有实际写入成功才报告已保存。
保留来源链接，不执行对外发布。
```

## 可选封面

```text
为“从资料到稿件：GardenFlow 首次创作”生成一张 3:4 竖版封面，使用当前已配置的图片服务。
主题是资料卡片逐步变成稿件和封面。米白背景、深绿色文字、少量鸢尾紫点缀，留白充分，简洁清晰。
主标题“从资料到稿件”，副标题“GardenFlow 首次创作”。不画虚构软件界面，不添加未验证的数字或商标。
生成一张即可；服务未配置时解释需要配置的项目，不报告成功。
将真实产物保存到媒体库供我检查，不对外发布。
```
