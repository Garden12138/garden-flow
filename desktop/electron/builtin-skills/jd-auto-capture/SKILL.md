# 京东商品自动采集操作规程

本任务由运行时结构化执行，不依赖模型截图或猜测坐标：

```
桌面 GardenFlow ── Desktop Bridge ── native host ── GardenFlow 插件
   │                                              │
   │  tab.create（京东商品链接）                  │  创建任务专用标签页
   │  capture.save + reviewOptions                │  识别商品、打开评价、采集评论
   │                                              │  assets.ingestProduct 入库
   │  tab.close                                   │  关闭任务创建的标签页
   │◀──── productId / snapshotId / 采集统计 ──────┘
```

## 每轮流程

1. 就绪检查确认商品链接均为京东详情页，且至少有一个已连接的采集插件实例。
2. 按每天轮换出的链接逐个创建受控标签页，等待页面加载，再调用 `capture.save`。
3. 评论标签留空时，插件自动采集好评、中评、差评各指定数量；填写标签后只采集对应标签。
4. 商品识别、评论滚动、去重、媒体下载和 `assets.ingestProduct` 入库全部复用侧栏保存链路。
5. 每个商品完成或失败后关闭任务创建的标签页；已经入库的商品会增加新的来源快照。

## 完成与异常

- 以桌面端返回真实 `productId` 和 `snapshotId` 为成功依据。
- 评论数量不足、标签缺失或部分评论图片下载失败时，保留已采集结果并在任务小结中列出提示。
- 单个商品失败不丢弃此前成功结果；其余商品继续处理。
- 登录或安全验证会停止本轮，不尝试绕过。
- 任务只采集公开页面，不读取 Cookie、隐藏账号标识或接口凭证。

## 排查

- 「京东商品链接」未就绪：只填写形如 `https://item.jd.com/商品编号.html` 的详情页链接。
- 「浏览器插件桥接」未就绪：打开采集浏览器，启用 GardenFlow 插件，并保持桌面端运行。
- 商品保存但评论为零：查看来源快照的评论采集提示，确认商品页面仍提供“全部评论/全部评价”入口。
