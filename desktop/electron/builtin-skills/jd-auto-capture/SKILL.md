# 京东商品自动采集操作规程

本任务由运行时结构化执行，不依赖模型截图或猜测坐标：

```
桌面 GardenFlow ── Desktop Bridge ── native host ── GardenFlow 插件
   │                                              │
   │  research.run（京东关键词）                  │  页内搜索并读取商品卡片
   │  tab.create + capture.save                   │  打开商品、采集详情与评论
   │                                              │  assets.ingestProduct 入库
   │  tab.close                                   │  关闭任务创建的标签页
   │◀──── productId / snapshotId / 采集统计 ──────┘
```

## 每轮流程

1. 就绪检查确认至少配置一个采集关键词，且至少有一个已连接的采集插件实例。
2. 每天从关键词列表轮换一个关键词，通过 `research.run` 在京东页内搜索框提交关键词，等待动态结果并滚动读取去重后的商品卡片；搜索生命周期与小红书任务一致。
3. 按搜索结果逐个创建受控商品标签页，等待页面加载，再调用 `capture.save`，评论配置通过 `reviewOptions` 一并传入。
4. 评论标签留空时，插件自动采集好评、中评、差评；填写标签后只采集对应标签。每个标签持续滚动，直到页面不再产生新评论，不设置条数截断。
5. 商品识别、评论滚动、去重、媒体下载和 `assets.ingestProduct` 入库全部复用侧栏保存链路。买家评论与商家回复完整保存为独立字段。
6. 商品采集时将详情页切到前台，侧栏显示“自动任务采集中”；`capture.save` 入库成功后在同一次插件调用中关闭详情页，遇到 Chrome 临时禁止编辑标签页时自动重试，桌面端仍保留兜底关闭。整轮结束后再关闭任务创建的搜索页。已经入库的商品会增加新的来源快照。

## 完成与异常

- 以桌面端返回真实 `productId` 和 `snapshotId` 为成功依据。
- 评论数量不足、标签缺失或部分评论图片下载失败时，保留已采集结果并在任务小结中列出提示。
- 单个商品失败不丢弃此前成功结果；其余商品继续处理。
- 登录或安全验证会停止本轮，不尝试绕过。
- 任务只采集公开页面，不读取 Cookie、隐藏账号标识或接口凭证。

## 排查

- 「采集关键词」未就绪：至少填写一个希望在京东搜索的商品关键词，多个关键词可用逗号或换行分隔。
- 「浏览器插件桥接」未就绪：打开采集浏览器，启用 GardenFlow 插件，并保持桌面端运行。
- 「京东关键词搜索未成功：search_input_unavailable」：当前插件版本过旧，尚未识别京东新版带 `aria-label="搜索"` 的搜索框；更新应用及内置插件后重试。
- 「京东关键词搜索未成功：results_not_ready」：当前插件版本过旧，只识别商品链接，无法读取新版通过 `data-sku` 驱动的商品卡片；更新应用及内置插件后重试。若页面跳到京东登录页，新版会明确提示登录，不再误报结果未就绪。
- 商品保存但评论为零：查看来源快照的评论采集提示，确认商品页面仍提供“全部评论/全部评价”入口。
- 侧栏仍显示“预览商品及评论”：自动任务直接调用与按钮相同的 `capture.save` 处理器，不模拟坐标点击；新版会在详情页打开期间把按钮切换为“自动任务采集中”并显示结果。
