# 小红书自动发布安全规程

发布能力由桌面运行时和独立插件结构化执行。模型不得自行点击发布，不得把普通对话解释为发布授权。

## 授权边界

- 每个授权绑定 `projectPath + revision + contentDigest`；内容变化后旧授权立即失效。
- 只有确认卡按钮，或严格分类为高置信度纯肯定答复的文字，才能进入发布队列。
- 同一句回复只要包含标题、正文、话题或媒体修改要求，就先修改并为新版本重新确认。
- 页面存在用户草稿、发布页数量不是一个、登录失效或出现安全验证时必须停止。

## 发布与恢复

1. 发布插件回读标题、正文和媒体，全部一致后只点击一次发布。
2. 识别“发布成功”页面后先记录已经发布，再等待自动返回或点击“立即返回”。
3. 最终确认同一标签页为空白发布页，才报告完整完成。
4. 发布成功但页面恢复失败时只能重试恢复；提交结果未知时必须人工核对，禁止直接重发。
