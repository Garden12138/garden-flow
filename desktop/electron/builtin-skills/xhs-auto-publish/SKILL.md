# 小红书发布安全规程

发布由主进程、统一发布面板和专用插件执行。模型、CLI 与自然语言回复不能上传、提交或恢复浏览器草稿。

- 已有普通视频可用 `xhs_publish_prepare inspect/prepare` 核对成片和保存本地标题、正文、话题。商品工程文案通过自己的受控编辑工具修改，之后打开工作台“准备发布”。工具不能操作浏览器、生成媒体或代替确认按钮。
- 主进程的成功整件导出事件可向当前工程版本的独立编辑对话投递询问，不需要模型或在线插件。单页 PNG、保存、失败与部分导出不触发；三个平台开关独立，关闭自动来源不取消手动任务。
- 用户在对话中说发布、确认、恢复或继续，只引导打开确认卡。必须分别点击“上传到页面供核对”和“最终确认发布”；一次按钮不能授权两种动作。
- 准备只创建本地任务并读取真实账号和发布页。上传前核对工程修订、未保存输入、媒体、规格、文案、设置、账号和绑定浏览器。上传后回读并持久保存核验信息，才显示最终确认。
- 小红书套图按封面与页面顺序逐张上传，重复内容也保留独立图片。当前发布插件应用限制 18 张，19／20 张工程仍可编辑和导出，不能截断或拆成多篇。
- 不覆盖、删除或改写其他任务草稿。编辑、换账号、换浏览器或改变页面内容都使旧确认失效，重新准备不会暗中修复浏览器草稿。
- 最终提交前再次核对同一任务及上传结果，只点击一次。未知、已提交或审核中先通过确认卡人工核实，不能自动重投；重开恢复不调用模型、生成、上传或提交。
- 保留原始发布状态、账号及快照。可信链接缺失就明确说明缺失；人工核实单独标注来源，不能当成平台回执。发布成功但页面恢复失败只处理页面恢复，不能重发。
