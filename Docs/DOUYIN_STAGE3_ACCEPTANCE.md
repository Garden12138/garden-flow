## 已实现的工程边界

- 抖音版本以空间 ID 和来源工程建立关系，保留小红书稿件路径、修订及商品资料版本。旧小红书稿件和发布任务不迁移、不改写。重复创建打开已有版本，明确选择“再复制一版”才创建新的工程。
- 复制素材、时间线、旁白和 BGM 至新工程目录；新工程清除来源导出回执及撤销记录。抖音版本单独保存内部标题、描述、话题、封面素材 ID 和修订号；商品资料改变只提示复核。
- 抖音发布任务绑定版本修订、当前 MP4 导出、内容摘要、空间、浏览器实例及目标账号。确认前及上传准备后再次校验，提交中断进入结果未知；网页明确回报审核时保持“已提交、待审核”，不记作已发布。
- `desktop/shared/platformPublisher.ts` 提供两个平台的公共请求基础、平台命令、浏览器／账号目标、提交状态与结果类型。小红书旧请求和持久化字段不迁移；浏览器命令显式携带平台，抖音请求强制携带独立版本、成片和目标账号。
- 发布插件只申请小红书和抖音创作者站点权限。抖音页面必须能读出唯一账号、视频上传控件及可回读的媒体和文案；无法识别或已有其他草稿时停止。旧小红书插件仍按原流程运行，旧版本插件不会被授予抖音实际执行能力。
