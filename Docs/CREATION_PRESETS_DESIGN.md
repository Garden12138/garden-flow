# 图文创作入口与预设改造方案

[文档首页](./README.md) · [三栏创作工作台](./CREATION_WORKBENCH.md) · [商品创作](./PRODUCT_CREATION.md) · [架构](./ARCHITECTURE.md)

状态：三期核心功能已实施。本文保留设计依据与技术边界；当前使用方法见[三栏创作工作台](./CREATION_WORKBENCH.md)。普通卡片提供导出供手动上传，扫描件 OCR、复杂关系网络及自动发布不在本次交付范围。

## 1. 改造结论

保留「电商套图、文章卡片、图解卡片、演示卡片」对应的创作需求，取消四个并列的提示词入口，将它们纳入现有平台选择和三栏创作工作台。

| 当前入口 | 拟用名称 | 产品定位 | 处理方式 |
| --- | --- | --- | --- |
| 电商套图 | 商品套图 | 基于真实商品与素材制作成套图片 | 合并到已有「商品套图」能力，统一入口、工程、导出与发布 |
| 文章卡片 | 文章转卡片 | 把文章或文档转成多页内容 | 作为图文笔记的创作预设，并提供文档上下文入口 |
| 图解卡片 | 知识图解 | 用流程、对比等方式解释内容 | 作为图文表达方式，可与文章转卡片组合 |
| 演示卡片 | 步骤教程 | 展示操作步骤、产品用法或案例过程 | 作为图文内容结构预设，降低首页入口优先级 |

新对话以「选择平台」作为主要创作入口；选择能力后立即进入可保存的空白作品。预设在工作台内按需选择，不增加必须完成的前置向导。

本期范围是现有平台能力的整合与图文交付补齐。图文预设首先适配小红书；不新增抖音／TikTok 图文发布能力，不扩展为通用电商详情页系统、幻灯片系统或自由绘图工具。

## 2. 产品价值与当前问题

### 2.1 价值判断

| 场景 | 用户收益 | 价值成立的条件 | 建议投入顺序 |
| --- | --- | --- | --- |
| 商品套图 | 用已有商品资料持续制作、调整和发布作品 | 商品真实、素材可追溯、文案可改、图片可导出 | 优先完成入口合并，复用成熟能力 |
| 文章转卡片 | 减少阅读、提炼、拆页和重复排版 | 能读取原文、保持事实依据，并交付成品卡片 | 优先完成完整输出流程 |
| 知识图解 | 降低流程、关系和对比内容的理解成本 | 图解结构清楚、文字准确、结构可编辑 | 先支持模板化图解，再扩展复杂形式 |
| 步骤教程 | 把方法和操作过程组织成可执行内容 | 步骤有顺序、操作与配图对应、注意事项明确 | 复用图文模板，随后完善 |

以上基于场景价值和现有实现判断，尚无使用数据支撑真实需求频率。发布后以初稿完成、成品导出和重复使用情况验证投入方向。

### 2.2 当前实现的限制

- 新对话四个按钮主要向输入框填入提示词，未携带统一的作品绑定、来源引用和预设标识。
- 附件中还有「做成文章卡片」「做成图解卡片」「生成电商套图」等入口，部分提示词包含默认平台或直接生成要求，与新的工作台流程存在差异。
- 四个名称混合了业务场景、内容来源和表达方式，用户难以判断它们与「选择平台」的关系。
- 普通图文支持逐页方案、媒体绑定及素材包；商品套图已有模板排版和 PNG／目录／ZIP 导出。普通图文尚不能直接获得同等完整的可编辑卡片交付。
- 当前商品套图要求真实商品及商品素材，不能通过虚构商品、放宽商品校验来承载普通文字卡片。

## 3. 统一产品模型

### 3.1 分工

| 维度 | 负责内容 | 示例 |
| --- | --- | --- |
| 平台 | 画幅、规格、能力可用范围和发布约束 | 小红书、抖音、TikTok |
| 创作能力 | 作品类型、编辑器、生成和导出入口 | 图文笔记、商品套图、商品视频、梦境故事 |
| 输入方式 | 内容从何而来 | 自由输入、文章／文档、商品资料 |
| 内容表达 | 页面如何组织信息 | 自由表达、知识图解、步骤教程 |
| 页面模板 | 单页如何排版 | 标题正文、图文分栏、对比、步骤 |
| 视觉样式 | 整套作品的颜色、字体与间距 | 简洁文字、图文混排 |

「文章转卡片」与「知识图解」允许组合。例如，同一篇文章可以输出观点卡片，也可以输出步骤图解。预设只初始化配置与内容组织策略，不持续覆盖用户后续修改。

### 3.2 对用户展示的预设

在「小红书 → 图文笔记 → 作品编辑」顶部显示可选的「创作方式」：

| 预设 | 默认输入与组织方式 | 默认页面建议 |
| --- | --- | --- |
| 自由创作 | 用户主题或手动填写 | 按内容需要组织 |
| 文章转卡片 | 绑定文章／文档，提炼观点与依据 | 封面、观点、展开、案例、总结 |
| 知识图解 | 围绕一个核心问题组织关系 | 问题、流程／对比／清单、结论 |
| 步骤教程 | 围绕目标组织操作过程 | 目标、准备、步骤、注意事项、总结 |

选择「文章转卡片」后，可在同组的「内容表达」设置中选择普通卡片、知识图解或步骤教程；更改表达方式保留文章来源。其他预设同样可以补充文档来源，来源只在用户明确移除时解除绑定。

建议页数不作为保存条件。用户可以保留空白、只完成部分页面，或修改默认顺序。完整内容与媒体校验在导出和发布时执行。

商品套图独立使用现有商品能力，可以提供卖点、场景和细节等内容建议，不在普通图文预设中重复实现商品创作流程。

## 4. 入口与用户流程

### 4.1 从新对话开始

1. 用户点击「选择平台」，选择已有支持的平台与创作能力。
2. 立即创建作品，绑定创作对话，进入「创作对话｜作品编辑｜效果预览」。
3. 图文笔记默认自由创作，用户可选择其他预设，也可直接聊天或填写页面。
4. 用户点击「生成初稿」或发送创作要求，AI 读取已绑定来源和当前作品，再通过结构化工具保存初稿。
5. 用户持续修改、预览和导出；需要 AI 配图时单独确认生成。

进入工作台、选择预设和填写空白作品本身不自动请求模型。对话和「生成初稿」使用所配置文本模型；界面应区分文本模型调用与媒体生成。

新对话不再常驻展示原四个提示词按钮。入口替换应与对应预设可用版本同时交付，避免先移除入口再补齐能力。

### 4.2 从文章或文档开始

1. 在附件或已有文档操作区选择「文章转卡片」，可进一步选择图解表达。
2. 平台与能力已明确时直接进入；尚未明确时只补选缺失项，不静默假定平台。
3. 创建作品并携带可持久化的来源引用，打开三栏；来源读取状态在作品编辑中可见。
4. 用户可先填写或修改要求。来源成功读取后，才允许基于该来源生成初稿。
5. 无法读取、内容为空或解析失败时显示具体状态及重试／更换来源入口，保留作品和已有输入。

已上传但仅存在于临时附件中的文件，需要先保存到当前空间管理的来源存储。取消平台选择不创建作品、不调用模型，保留原附件和输入。

### 4.3 从商品或商品图片开始

- 已选择商品：点击「制作商品套图」，携带商品引用进入现有商品套图工作台。
- 仅上传图片：可以保存创作草稿，提示绑定已有商品或补充资料创建商品；识别出的名称与卖点只能作为待核对建议。
- 商品未绑定时不编造商品信息，不触发最终商品方案校验或媒体生成。商品确认后沿用现有素材归属、商品快照和版本校验。
- 图文和商品图片能力仍只显示当前支持的平台，不能因快捷入口绕过能力矩阵。

### 4.4 在已有作品中更换预设

空白作品可直接更换配置。已有内容时，先展示会改变的字段与页面，由用户选择仅调整后续创作方向，或重新组织当前内容；应用后可整体撤销。

更换预设不创建新会话，也不隐式重写全部页面。切换平台或创作能力继续使用「另建版本」，新版本有独立对话和来源作品链接。

## 5. 三栏中的职责

| 区域 | 改造内容 |
| --- | --- |
| 创作对话 | 描述目标、补充素材、提出局部修改；显示实际保存摘要、读取失败和未应用修改 |
| 作品编辑 | 创作方式、来源、目标读者、内容、逐页结构、模板、视觉样式、素材与发布文案 |
| 效果预览 | 显示当前选中页的本地排版，支持翻页，并区分排版预览与已生成图片 |
| 顶部操作 | 作品名称、保存状态、撤销、版本、生成初稿、生成配图及适用的导出／发布入口 |

选择某页后，预览定位到该页，对话获得页面 ID 和当前内容。预设与来源设置放在可折叠分组中，不占用每页编辑的主要空间。

沿用默认约 30%／40%／30% 的可拖动三栏、历史侧栏进入时收起及退出时恢复的行为。工作区不足 1000px 时保留对话，通过按钮切换编辑与预览。

## 6. 普通卡片的成品交付

### 6.1 首批模板

| 模板 | 使用场景 | 必须支持的编辑内容 |
| --- | --- | --- |
| 封面 | 主题与读者收益 | 标题、副标题、可选配图 |
| 标题正文 | 观点、解释、案例 | 标题、正文、重点标记 |
| 图文分栏 | 文字与配图说明 | 文案、素材、裁切与位置 |
| 对比 | 两种方案、前后差异 | 对比项、列标题、各项内容 |
| 步骤 | 教程或线性流程 | 步骤顺序、名称、说明、可选配图 |
| 总结清单 | 要点回顾与行动建议 | 清单项、结语 |

文字、步骤和对比关系保存在结构化页面中，由应用模板排版，保持文字可编辑。AI 配图作为独立素材绑定；修改标题或步骤文字不需要重新生成整张背景图。

首批知识图解支持线性流程、对比和清单。复杂关系网络、自由节点连线、矩阵与时间线后续评估，未实现时明确提示当前模板范围。

### 6.2 预览与导出

- 文字卡片不要求商品或图片素材；支持纯手动填写后预览和导出。
- 首期普通卡片采用明确的图文输出规格；小红书可先采用现有套图的 3:4、1440×1920，作为新增卡片模板的默认规格。
- 预览与导出使用同一页面模型、模板版本和字体资源，导出前校验文字溢出、缺失素材和损坏引用。
- 支持单页 PNG、整套目录和 ZIP，包含有序图片、发布文案和作品清单；用户打开原作品后仍能编辑文字与结构。
- 保留当前套图工程最多 20 页的边界；进入现有小红书套图发布流程时按应用最多 18 张校验，不自动截断、拆分或忽略页面。
- 普通卡片能否发布取决于对应作品与发布适配器的明确接入和验证。首期可以仅提供导出供手动上传，不因获得 PNG 就自动显示发布能力。

复用商品套图的字体、渲染、素材解析、文件打包与缓存基础，提取独立的通用页面渲染层。商品套图继续保留商品专用文档与校验，普通卡片使用图文原生文档扩展。

### 6.3 状态与失效

文案和排版变化立即更新本地预览。页面导出指纹包含内容、模板、样式、字体版本、画幅与素材哈希；发生变化时将已有导出标记为「待更新」，保留旧文件供查看。

仅重新渲染受影响页面。批量导出中部分失败时展示失败页和原因，允许单页重试；不把部分完成标为整套完成。修改发布文案只更新相关文案与确认状态，复用仍有效的页面图片。

## 7. 作品数据与结构化接入

### 7.1 数据边界

复用现有 `CreationWorkbench`、`CreationWorkspace` 和能力适配器。三个普通图文预设继续使用 `note-image`；商品套图继续使用 `product-image-set`，不为每个预设新增创作能力。

拟增加的结构化配置包括：

| 字段 | 含义 |
| --- | --- |
| `presetId` / `presetVersion` | 开始时选用的预设及版本，用于恢复与兼容 |
| `inputMode` | 自由输入、文章来源等输入方式 |
| `expression` | 自由表达、图解或步骤等内容组织方式 |
| `sourceRefs` | 当前空间内可验证的附件、知识、稿件、素材等来源引用及版本 |
| `page.sourceRefs` | 页面使用的来源位置，例如章节、段落或页码 |
| `page.layout` / `page.blocks` | 实际排版模板及文字、图片、步骤、对比等结构化内容 |

`presetId` 记录初始化来源，`inputMode` 和 `expression` 保存用户当前选择。例如「文章转卡片＋知识图解」不要求创建第五种能力或预设。预设升级不自动重排已有作品。

在原生作品尚未创建时，草稿控制器保存配置与内容；原生作品创建后，由原生文档保存可编辑内容与配置，公共工作记录负责作品索引和绑定。每个生命周期阶段只有一份可编辑内容，三栏、聊天和导出不各存一份副本。

扩展 `XhsNoteDocument` 时需要新增版本识别与显式迁移，不能丢弃现有 `imagePages`、媒体槽位及素材包信息。旧页面可保留兼容表示，在用户编辑或应用模板时转换，保留稳定页面 ID 与素材引用。

### 7.2 统一启动契约

在现有 `creation.start` 和创建 IPC 中增加经过校验的初始化信息：预设、来源引用、入口来源和请求幂等标识。启动端和主进程共同校验平台／能力／预设组合，主进程负责最终校验来源归属。

重复点击或请求重试返回同一创建结果；从旧对话转入创作时携带来源关系。素材读取失败不回退到普通对话重新创建另一份作品。

### 7.3 来源读取

为受限编辑流程补充「读取已绑定来源及解析结果」的工具契约，或扩展现有读取工具。不能假设现有 `creation_read` 已支持任意附件解析，也不能开放任意本地路径读取来绕过来源绑定。

来源先按空间与所有权验证，再调用已有解析能力。提炼结果保留出处和原始版本；内容没有依据时标记待补充，不编造数据、案例或商品参数。原文变化后提示来源版本变化，用户选择重新读取，不自动改写现有页面。

### 7.4 保存与并发

沿用普通修改自动同步、约 600ms 自动保存、发送前保存、保存失败保留输入、版本校验、请求幂等、撤销及恢复机制。

模板配置和页面重组作为同一逻辑修改提交，版本校验同时覆盖配置与实际页面。AI 等待期间用户有新输入时，旧修改保留为未应用结果，不覆盖新内容。撤销恢复内容与配置，但不恢复已失效的媒体生成或发布授权。

## 8. AI 编排与确认规则

图片导演技能继续负责整套内容目标、页面顺序、统一风格和逐页视觉建议；与预设描述共同提供决策原则。运行时根据显式能力、配置、来源和作品绑定选择流程，不以聊天关键词或按钮文案匹配路由。

AI 每轮读取最新作品、当前选中页和可访问的来源，通过受限结构化工具保存。完整初稿包含页面顺序、文案、适用模板、素材需求、来源依据及发布文案；保存成功后对话才能报告已修改。

| 操作 | 交互规则 |
| --- | --- |
| 文案、步骤、页面和排版普通修改 | 直接同步，可撤销 |
| 已有内容更换预设并大范围重组 | 展示变更范围，由用户选择应用方式 |
| 确定性模板排版与本地 PNG 导出 | 使用当前内容本地执行，不调用媒体生成模型 |
| AI 图片、视频、配音生成 | 独立展示方案、模型与请求范围，明确确认后执行 |
| 上传与发布 | 沿用已有能力的分步确认与失效校验 |

需要同步修改内置技能和附件提示中的默认平台、自动生成与「先采用方案」约定：普通策划结果直接进入作品编辑；媒体生成仍独立确认。模型工具权限不因加载技能而扩大，技能不能绕过工作台绑定直接提交生成或发布。

## 9. 历史与旧入口兼容

- 已有商品套图、普通图文、收藏与归档保持原作品和原会话绑定，旧作品链接继续进入三栏。
- 旧按钮的内部标识可以映射到新入口和预设，但不通过识别用户消息文字来判断迁移目标。
- 原普通对话没有作品绑定时，由用户点击「转为作品」创建新作品并记录来源对话；不把全部旧消息自动并入新对话，也不覆盖旧消息。
- 历史 AI 图片可以作为明确选择的素材引用，不能仅根据消息文字推断它属于某页或某商品。
- 旧作品没有预设字段时按自由创作读取；打开不会自动调用模型或重排页面。缺失来源时仍可编辑已有内容。
- 跨空间不继承不可访问的来源。复制作品时，对可复制素材生成目标空间引用；无法复制的内容显示待补充，不能保留失效的访问授权。

## 10. 分期交付

各期以可交付行为划分，不包含对尚未完成能力的上线承诺。

| 阶段 | 交付内容 | 完成边界 |
| --- | --- | --- |
| 第一期：入口与绑定统一 | 商品套图合并；普通图文预设配置；文档和商品上下文交接基础；来源携带与历史恢复 | 已替换入口进入同一作品与三栏，不再开启独立提示词流程；未提供成品能力时明确显示为卡片方案 |
| 第二期：文章卡片完整交付 | 来源读取；文章提炼；基础卡片模板；本地预览；PNG／目录／ZIP 导出 | 从真实文章或纯手动输入到可编辑卡片和最终图片完整可用，来源失败与排版失败可恢复 |
| 第三期：图解与教程完善 | 线性流程、对比、清单、步骤模板；文章与表达方式组合；模板重组预览 | 关系与步骤可编辑，切换预设不丢内容；高级形式按实际支持范围展示 |

第一期只替换已有等效能力的入口；文章转卡片的完整产品入口随第二期交付。不能仅修改按钮名称，就把卡片策划标记为成品制作。

## 11. 验收与验证

| 范围 | 验收要求 |
| --- | --- |
| 进入工作台 | 平台选择、文档附件、已有稿件、商品引用均正确绑定；取消与重复点击无多余作品或模型请求 |
| 纯手动创作 | 空白保存、逐页编辑、排版预览、保存恢复、图片导出可在无模型配置时完成 |
| 文章转换 | 读取实际内容；保留来源依据；读取失败可重试；来源变化不自动覆盖作品 |
| 表达组合 | 同一文章可选择图解或教程；重组前显示范围，应用后可撤销 |
| 双向同步 | 对话修改后编辑和预览更新；手动修改后下一轮 AI 使用最新值和所选页 |
| 失败与并发 | 保存失败、过期 AI 结果、失效引用、图片生成失败和部分导出失败均保留输入并有明确恢复入口 |
| 图片交付 | 纯文字、中文长文、混排、对比和步骤页可导出；溢出指明页面，不能静默裁掉内容 |
| 商品边界 | 普通卡片不依赖商品；商品套图仍校验真实商品、素材归属和版本 |
| 历史与空间 | 重启恢复同一作品与会话；旧链接、收藏、归档可用；跨空间引用受校验 |
| 生成与发布 | 普通编辑不触发媒体生成；确认绑定当前版本；普通图文不超出已有发布能力 |
| 布局与主题 | 960px、1200px、1440px 及明暗主题下可用；窄屏切换、拖动、折叠和历史侧栏恢复正常 |

实施时补充入口绑定、来源解析、预设组合、原生文档迁移、并发保存及渲染指纹的相关回归测试，运行 `pnpm test`、`pnpm check`，并在隔离 Electron 环境验证实际操作。真实付费服务、上传与发布验证另外明确范围。

本文档自身的链接检查命令为 `pnpm check:docs`；可复现的自动检查与隔离应用验证命令见[测试文档](./TESTING.md)。真实付费生成、上传与发布需要单独验证。

## 12. 效果评估

优先观察从进入作品到有效初稿、从有效初稿到整套导出的完成率，以及完成耗时、重复使用、来源读取失败、溢出与导出失败情况。分别统计文章、图解、教程和商品套图，避免用按钮点击量替代最终产出价值。

指标中的「有效初稿」应有可保存的实质页面内容，「成功导出」应对应用户选择的完整范围；二者均不以 AI 在对话中宣称完成为依据。

优先使用本地汇总；若后续引入远端统计，应单独设计用户设置与数据范围，不默认上传原文、提示词、商品信息、图片或来源路径。
