# 已有视频片段混剪首版

2026-10-12。用户已选择路线图中的已有视频片段混剪任务。本轮在现有商品视频工作流中增加明确的混剪模式，保留商品图文套图和普通商品视频行为。

## 范围与验收

- 选择一个 `@商品` 后，通过“视频混剪”选择当前空间媒体或本地自有视频，最多八个来源。主进程读取时长、尺寸、帧率、音轨与内容摘要，来源不直传视频模型。
- 技能依据商品事实和来源元数据提出片段顺序、截取区间、屏幕文字及适配方式；未知画面内容不得宣称已经理解。确认卡展示真实来源视频、截取区间和声音设置。默认不生成图片、视频或旁白。
- 沿用持久分镜确认、商品版本失效和提案幂等；来源更新、删除、越界或跨空间时阻断旧方案。确认后复制来源进入独立工程，后续源商品／源视频变化不修改已有工程。
- 默认 1080×1920、30fps，支持原有画布比例；截取点对齐输出帧，不允许超出来源或用冻结画面补足。支持改字幕、截取、顺序、完整展示／裁切、原声音量、片段替换与删除；复用本地 BGM、撤销及导出。
- 预览和导出共用剪辑数据，MP4 入库，编辑后输出过期；退出重开保留来源副本、区间、字幕、声音和输出记录。首版不增加自动付费媒体生成或新的发布流程。
