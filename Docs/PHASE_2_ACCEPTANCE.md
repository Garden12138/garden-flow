# 阶段 2 京东商品评论采集验收记录

## 结论

阶段 2 的功能实现与自动化验收于 2026-09-14 通过。京东商品评价弹窗中的可见筛选标签、采集数量、评论正文、脱敏用户名、日期、规格、买家秀图片和视频标记已接入商品来源快照；评论图片与商品主图、详情图分开保存。资产库只负责查看、整理和引用采集结果，不提供 AI 详情页生成或评论编辑器。

真实京东页面已经完成一条自定义标签端到端验收。默认三类采集在首次实测时暴露了标签切换后的异步刷新竞态，表现为“好评 0、中评 0、差评 5”；实现已改为等待临时空列表或加载状态结束，并加入对应自动化回归。由于最终验收时无法控制装有扩展的 Chrome 会话，发布前仍需使用最新打包版本补测“未打开评价弹窗”和“默认三类各 5 条”两条真实页面链路。

## 部分完成规则

- 评价弹窗未打开时，商品资料照常保存，评论状态为 `not-opened`。
- 标签缺失、评论数量不足、加载超时或部分图片下载失败时，已经取得的数据继续保存，快照按标签记录请求数、实际数和原因。
- 评论图片下载失败时保留原始京东来源与失败状态；视频只记录是否存在及页面公开提供的来源地址。
- 采集只读取页面公开可见内容，不读取浏览器账号、Cookie、隐藏用户 ID 或接口凭证。
