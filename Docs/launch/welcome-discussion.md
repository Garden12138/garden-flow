# 👋 欢迎来到 GardenFlow

<!-- 发布位置：Discussions / 公告。本文为草稿；链接须在默认分支上线后核对。 -->

GardenFlow 把资料、选题、AI 写作和媒体资产放在同一个本地优先的工作空间。欢迎从一篇有来源的介绍稿开始体验。

- [下载安装包](https://github.com/Garden12138/garden-flow/releases/latest)
- [首次创作教程](https://github.com/Garden12138/garden-flow/blob/main/Docs/FIRST_CREATION.md)
- [输入资料与提示词](https://github.com/Garden12138/garden-flow/tree/main/examples/first-creation)
- [实际稿件与封面](https://github.com/Garden12138/garden-flow/tree/main/examples/first-creation/output)
- [路线图](https://github.com/Garden12138/garden-flow/blob/main/ROADMAP.md)

首次使用需要自行配置文本模型；封面单独配置图片服务。项目采用非商业 Source-Available 许可证，当前安装包未进行 Apple 公证或 Windows 代码签名。工作空间默认在本机，外部模型请求按你的配置发送。

使用问答可以写清：你希望完成什么、系统与版本、停在哪一步、看到什么结果。作品分享欢迎附公开来源、提示词、实际产物，以及你做了哪些人工修改。

可复现问题请用 [Bug report](https://github.com/Garden12138/garden-flow/issues/new?template=bug_report.yml)，具体功能建议请用 [Feature request](https://github.com/Garden12138/garden-flow/issues/new?template=feature_request.yml)。安全问题走 [Security](https://github.com/Garden12138/garden-flow/security)。不要附密钥、Cookie、私人路径或私密内容。

如果愿意帮助改进首次体验，欢迎回复：完成了哪一步、最卡的一步、希望优先改进什么。没有完成也很有价值，无需为了反馈而先 Star。
