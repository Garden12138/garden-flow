# 真实演示录制脚本

主题：用 GardenFlow 介绍 GardenFlow。只录制[公开示例](../../examples/first-creation/README.md)对应的真实操作。成片必须以[运行记录](./run-record.md)为依据。

## 录制准备

- 使用独立测试空间，只加入公开资料。
- 原始记录保留版本、模型、开始/结束时间和人工操作；录制时不要显示密钥、私有 Endpoint 或个人路径。
- 首次教程先验证文字稿闭环；图片服务单独验证。
- 记录真正的交互过程。不要把静态截图轮播称为操作录屏，不用生成图冒充应用界面。

## 25 秒短演示

| 时间 | 画面 | 字幕 |
| --- | --- | --- |
| 0–4 秒 | 打开本次公开资料和来源 | 从已有资料开始 |
| 4–8 秒 | 查看候选并选择角度 | 选一个值得写的角度 |
| 8–14 秒 | 正文、引用与人工核对 | 带来源写作，人工核对 |
| 14–20 秒 | 本次实际生成的封面 | 图片服务单独配置 |
| 20–25 秒 | 打开保存稿件与媒体文件 | 稿件与封面留在同一空间 |

全片标注“过程剪辑，已省略模型等待”。角落放版本。封面失败时保留失败记录，不制作暗示成功的成片；可先发布清楚标注范围的文字流程演示。

## 2～3 分钟操作视频

| 时间 | 内容 |
| --- | --- |
| 0:00–0:20 | 展示实际结果，说明输入和模型前提 |
| 0:20–0:45 | 添加公开资料、检查来源与索引 |
| 0:45–1:10 | 选择来源、提出角度、人工选择 |
| 1:10–1:50 | 生成正文、核对来源、展示真实修改 |
| 1:50–2:20 | 保存稿件、重新打开；说明保存方式 |
| 2:20–2:50 | 独立图片配置与真实封面，定位媒体文件 |

若实际操作不适合在 3 分钟内解释，优先保留清楚的步骤；在说明中注明实际模型耗时。配置页面只展示字段名称或遮蔽后的公开示例，不能为演示填入并运行虚假服务。

## 导出与使用

主视频用 H.264 MP4，画面 16:9；短预览 GIF 宽度约 960 px，控制在 5 MB 内，正文提供完整视频链接。逐帧检查关键字幕、来源、实际结果和隐私；只有本次实际生成结果才能配合自用主题首发。

当前已生成 960×640、约 22 秒的[截图流程预览](../../images/first-creation-demo.gif)，大小低于 1 MB，内容来自本次实际输入与产物。它明确标注模型等待已省略，不替代仍待录制的 2～3 分钟连续操作视频。
