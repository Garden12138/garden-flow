# GardenFlow 使用手册

## 1. 适用范围

本手册以当前 Electron 开源快照为准。产品展示名是 GardenFlow；文件或日志中出现旧名称时，属于历史兼容标识。

开源版重点支持自定义 AI 源和本地工作空间。官方账号、会员、支付、生产浏览器桥和部分平台能力可能显示为空态或不可用；这类降级不影响核心的本地知识、AI 对话、稿件和媒体工作流。

## 2. 首次使用

### 2.1 选择工作空间

默认工作空间为：

```text
~/.gardenflow
```

工作空间存放知识、稿件、媒体、资产、Skills 和 GardenFlow 产物。可在 `设置 → 通用` 修改目录。

建议：

- 使用独立目录，不要直接选择某个现有 `manuscripts` 文件夹。
- 把一个账号、品牌或业务线放在一个“空间”中。
- 切换空间前等待正在保存或生成的任务完成。

### 2.2 配置 AI 源

进入 `设置 → AI`：

1. 新增或选择供应商预设。
2. 选择协议。
3. 填写 Endpoint、API Key 和模型名称。
4. 测试连接或拉取模型列表。
5. 保存后回到“新对话”发送一句简单消息。

本地服务可使用：

| 服务 | Endpoint |
| --- | --- |
| Ollama | `http://127.0.0.1:11434/v1` |
| LM Studio | `http://127.0.0.1:1234/v1` |
| vLLM | `http://127.0.0.1:8000/v1` |
| LocalAI / llama.cpp | 常见为 `http://127.0.0.1:8080/v1` |

模型必须支持你的任务。纯文本模型不能直接读取图片、音频或视频；媒体生成、转录、Embedding 和视觉索引也需要各自兼容的模型路由。

### 2.3 认识主界面

新版桌面端使用“流程轨道 + 上下文书架 + 主画布 + 检查器”。流程轨道是一级入口，上下文书架显示当前阶段的历史、来源或下一步，文件与详细参数在右侧检查器中打开。

当前一级入口：

| 入口 | 用途 |
| --- | --- |
| 工作台 | 继续最近稿件、查看待审批与素材统计、发起快速任务 |
| 素材 | 导入、搜索、多选和引用资料 |
| 灵感 | 用素材托盘形成候选方向并转为创作简报 |
| 创作 | 与 GardenFlow 对话、研究、写作和执行任务 |
| 生成 | 生成图片、视频、音频、封面和数字人，并跟踪任务状态 |
| 资产 | 管理品牌、角色、物品和场景参考 |
| 媒体 | 查看与复用生成或导入的媒体结果 |
| 计划 | 按今天、接下来、运行中和异常管理自动化 |
| 设置 | 管理 AI、工作空间和运行配置 |

稿件编辑器、封面工作台和审批页从业务流程中打开。按 `Cmd/Ctrl+K` 搜索素材和稿件，按 `Cmd/Ctrl+N` 打开统一新建菜单，按 `Esc` 关闭最上层面板。

默认 GardenFlow 品牌配置只直接展示“AI”和“通用”设置。团队、平台、Skills、MCP、记忆、远程控制、工具和实验性设置是否出现，取决于构建配置、开发者模式或当前功能入口；未显示不代表安装失败。

## 3. 推荐的第一条工作流

用一份本地文档完成从素材到稿件：

1. 在“素材”点击“添加文件”，导入一份 Markdown 或文本。
2. 搜索并打开该资料，确认正文可读取。
3. 多选资料后选择带入“灵感”或“创作”；引用会随结构化交接保留。
4. 输入目标，例如：

   ```text
   根据这份资料写一篇 1200 字的公众号文章，先给出结构，再生成完整稿件；事实必须以资料为准。
   ```

5. 在创作简报中检查目标、受众、引用和交付形式；工具过程默认显示摘要，可按需展开。
6. 打开生成的稿件，在编辑器中修改并确认自动保存。

这条链路不依赖浏览器插件，最适合验证本地部署是否完整。

## 4. 创作与 GardenFlow

### 4.1 创建和管理会话

- 从统一“新建”菜单选择“新对话”，或在创作阶段开始新的创作简报。
- 历史会话显示在创作阶段的上下文书架，可重新打开、重命名、收藏、归档或删除。
- 应用会按会话保存消息、运行状态、工具结果和任务 checkpoint。
- 多个运行中的页面会尽量保持任务挂载；不要在任务刚开始时强制退出应用。

### 4.2 添加上下文

可以组合使用：

- 文本说明。
- 本地文件附件。
- 知识库引用。
- 资产库中的角色、品牌或其他主体。
- 顾问、团队成员或 Skills（入口是否显示取决于当前构建）。

附件发送前会按模型能力检查。若提示模型不支持某种输入，请切换多模态模型，或先把媒体转录/提取为文本。

### 4.3 写清任务

高质量任务至少包含：

- 目标：要产出什么。
- 受众与平台：写给谁、发布到哪里。
- 来源：必须使用哪些知识或附件。
- 约束：长度、语气、结构、禁用内容。
- 交付：保存为稿件、图片还是任务报告。

示例：

```text
使用已引用的三条知识素材，写一篇面向新手创作者的小红书图文稿。
要求：标题 10 个、正文 800 字以内、分 5 段、结尾带提问；不要编造素材中没有的数据。
完成后保存为稿件。
```

### 4.4 工具确认与取消

- 只读工具通常可直接执行。
- 写文件、外部操作或其他变更工具可能弹出确认。
- 检查工具名称、参数和目标路径后再批准。
- 长时间无响应时可取消当前会话；取消不会删除已保存的历史和已落盘产物。

### 4.5 团队与长任务

当任务带有显式多角色、自动化或长周期元数据时，系统可能创建 planner、researcher、copywriter、reviewer 等角色，并显示阶段、子任务和交接结果。

判断完成不要只看聊天文字，应同时确认：

- 目标文件或媒体是否真实存在。
- 工具回执是否成功。
- reviewer 是否指出缺口。
- 后台任务是否仍为 running。

## 5. 知识库

### 5.1 添加资料

空知识库页面支持：

- 添加单个文件。
- 添加文件夹。
- 绑定 Obsidian vault。
- 通过生产版浏览器插件采集网页和平台内容。

文档源有两种常见语义：

- 复制导入：内容进入 workspace，由 GardenFlow 管理副本。
- 跟踪目录/Obsidian：记录外部根路径并建立索引，源目录移动后需要重新绑定。

### 5.2 浏览和筛选

知识库会按小红书图文、视频、博主、评论、YouTube、网页、文档等类型展示。可使用搜索框、类型筛选、标签和来源查看内容。

打开详情后可：

- 查看正文、图片、元数据和来源链接。
- 在文件夹中显示本地文件。
- 将资料送入 GardenFlow。
- 对视频提取文字或重试转录。
- 删除单条或批量删除。

删除知识项可能同时移除 workspace 中对应目录。执行前先确认来源是否还有其他副本。

### 5.3 视频和 YouTube

- YouTube 导入需要 `yt-dlp` 能正常工作。
- 视频处理可能包含缩略图下载、字幕抓取、转录和 AI 摘要。
- “处理中”表示后台任务尚未结束；不要重复导入同一视频。
- 无字幕或网络受限时，可在详情中重试或改为导入本地转录文本。

### 5.4 视觉索引

开启视觉索引后，系统会调用视觉模型理解图片、PDF 页面和图文素材，便于后续搜索与引用。

注意：

- 会产生额外模型调用或本地算力消耗。
- 关闭后只是不再分析新内容，已有索引仍可能保留。
- 开启前先配置并测试视觉模型 Endpoint。

### 5.5 从知识到创作

优先从知识详情页发起创作，让系统携带结构化 `knowledgeReferences`，比手工复制整篇内容更利于保留来源和控制上下文。

## 6. 灵感桌

灵感桌用于从现有知识中随机漫步、手选素材或分析评论，然后在“素材托盘 → 候选方向 → 评价与约束”的三栏中形成创作方向。

推荐步骤：

1. 选择素材范围或来源模式。
2. 发起 brainstorm。
3. 比较主题、角度和证据是否足够。
4. 选择一个方向转入 GardenFlow。
5. 在新会话中补充平台、受众、稿件类型和交付要求。

转入 GardenFlow 时会携带选题、素材引用、任务提示和必要 Skills。若素材不足，先回知识库补充，不要让 AI 用猜测填满事实缺口。

## 7. 稿件编辑器

稿件编辑器从 GardenFlow 生成结果或稿件列表进入，不是独立一级导航。

主要能力：

- Markdown/结构化稿件编辑。
- 自动保存。
- 与稿件专属 AI 会话绑定。
- AI 修改 proposal 的接受或拒绝。
- 绑定媒体、片段和项目状态。
- 部分稿件可升级为带时间线的包稿并导出视频。

使用建议：

1. 打开后先确认标题栏中的文件名和路径。
2. 等待初次内容和媒体加载完成。
3. 对 AI 修改逐项审阅，不要在 proposal 未应用时误认为正文已改变。
4. 关闭前观察保存状态；自动保存有短暂防抖时间。
5. 重要版本可另存或在 workspace 中做外部备份。

## 8. 自由创作

### 8.1 通用流程

1. 选择图片、视频、音频、封面或数字人模式。
2. 填写标题、提示词、比例、时长、质量等参数。
3. 添加参考图、首尾帧、驱动音频或绑定稿件。
4. 提交任务。
5. 在 Feed 中查看队列状态、进度和产物。
6. 对失败任务重试或删除；对成功产物预览、保存、绑定或打开目录。

生成任务由主进程持久化。页面刷新或切换后，系统会从 job registry 恢复状态，但强制退出仍可能中断正在调用的远程任务。

### 8.2 图片与封面

- 图片模式适合自由配图、商品图和参考图变体。
- 封面模式可绑定稿件并使用标题、布局和风格开关。
- 参考素材越明确，人物、商品和品牌一致性通常越好。
- 生成后确认产物已进入媒体库或目标稿件，而不只是临时预览。

### 8.3 视频

根据模型能力可使用文本、参考图、首尾帧、首段视频或驱动音频。时长、分辨率和是否生成音频会影响费用与处理时间。

导出/自动剪辑还依赖 FFmpeg、Remotion 和本地媒体可读性。源文件移动或删除后，历史项目可能无法重新渲染。

### 8.4 音频与数字人

- TTS 需要已配置语音模型和 voice ID。
- 数字人通常要求先在资产库为角色上传带音轨的参考视频，并完成音色克隆。
- 音色克隆失败时检查样本长度、音轨、文件格式、模型路由和任务详情。

## 9. 资产库

资产库用于跨任务保持一致性，当前主要分类包括：

- 品牌
- 角色
- 物品
- 场景

可为资产保存名称、描述和最多若干参考图片。角色还可保存声音样本、音色映射和参考视频，用于配音或数字人。

建议：

- 一张图只保留清晰主体，减少背景干扰。
- 名称稳定，不要在不同任务中反复更名。
- 描述写可验证的外观、风格和禁用项。
- 声音/视频样本需确认拥有使用授权。

代码中存在商品和品牌工作区流程，但开源构建的官方 bridge 可能返回不可用；是否显示以当前界面为准。

## 10. 自动化

当前创建表单支持：

- 每小时
- 每天指定时间
- 工作日指定时间
- 每周指定星期和时间

操作步骤：

1. 点击新建任务。
2. 填写任务名称。
3. 选择计划和本地时间。
4. 输入完整 prompt，明确来源、动作和交付物。
5. 保存并确认任务已启用。
6. 先使用“立即运行”验证一次，再等待定时触发。

示例：

```text
从当前空间最近新增的知识中选择 3 条，生成一份下周小红书选题清单。
每条包含标题、目标受众、核心观点、引用来源和 5 句内容提纲；保存为稿件。
```

任务列表可查看下次执行时间、状态和产物，并可启停、编辑、删除或立即运行。失败时先检查 AI 源、后台任务日志和引用路径。

自动化依赖应用进程存活。系统休眠、网络中断或真正退出应用都会影响准点执行；恢复后的 missed-run 策略以任务配置为准。

### 10.1 在聊天中创建自动化任务

除了自动化页表单，你也可以直接在聊天里描述需求，例如“每天早上 9 点帮我采集猫粮相关的爆款笔记并出一份选题建议”。

流程如下：

1. AI 会先复述任务名、触发频率和将要执行的完整 prompt，信息不足时会追问；
2. 因为定时任务是长期后台副作用，创建和删除会弹出确认卡，需要你点击确认后才真正落库；
3. 创建成功后，聊天里会出现一张任务卡片，展示频率、下次运行时间和启用状态，并可直接暂停 / 立即运行 / 跳转自动化页；
4. 自动化页的任务列表会用来源徽标区分「手动创建」「对话创建」「内置」。

对话创建的任务与表单创建的任务是同一份数据，可在任意一侧继续管理。

### 10.2 内置任务：小红书自动采集

自动化页顶部的「内置任务」分组提供一个开箱即用的采集任务，**默认关闭**，需要手动开启。

它通过 [computer-use](https://github.com/Garden12138/computer-use) 驱动**真实 Chrome**（不使用 Playwright / Selenium / 调试端口），按关键词浏览小红书并点击 GardenFlow 插件的「保存网页 / 保存笔记」按钮，数据经现有插件通路入库。

**使用前提（缺一不可）：**

1. **系统平台**：computer-use v0.2 的浏览器配方仅支持 macOS，Windows / Linux 上该任务会置灰。
2. **安装 computer-use**：克隆仓库后执行

   ```bash
   ./scripts/build-helper.sh
   python3 -m pip install -e .
   computer-use doctor
   ```

3. **授予系统权限**：在「系统设置 → 隐私与安全性」中为 `ComputerUseHelper` 与你的终端授予**辅助功能**和**屏幕录制**权限，然后完全退出终端并重新运行 `computer-use doctor` 确认两项均为 true。
4. **添加 MCP 服务**：在任务卡片的就绪检查里点击「一键添加 computer-use MCP」，或到「设置 → MCP」手动添加 stdio 服务 `python3 -u -m computer_use --pacing conservative mcp`。
5. **登录 profile**：手动打开采集用的独立 Chrome profile（默认名 `ComputerUse`），**人工登录小红书**并确认 GardenFlow 插件已启用且原生消息通道已连通。这一步涉及账号凭据，不会被自动化。
6. **视觉模型**：操作循环依赖截图定位，请把当前 AI 源切换到支持图片输入的模型。

**配置项**：采集关键词（必填，多个用逗号分隔，每轮轮换取一个）、单轮最多保存笔记数（默认 5）、Chrome Profile 名称、操作节奏（默认保守）、每天执行时间（默认 10:00）。

**就绪检查**：卡片上的「检查就绪状态」会逐项校验平台、关键词、computer-use 可用性、系统权限、MCP 服务和插件桥接，未通过项会给出修复指引。任一项未通过时无法开启开关；已开启的任务在执行前再检查一次，不满足则本轮跳过并记录原因。

**安全须知**：

- 建议使用小号，并与日常账号使用不同的 Chrome profile；
- 执行期间 AI 会接管键鼠，请避免同时操作电脑；
- 技能规程限制 AI 只能在小红书域内浏览并点击保存按钮，禁止发布、评论、私信和账号设置类操作；
- 遇到登录失效、验证码或风控提示会立即停止并报告，不会尝试绕过；
- 高频采集仍有平台风险，请保持保守的单轮上限与执行频率。

首次使用建议先用「立即运行」跑一轮验证采集入库链路，稳定后再依赖定时调度。

## 11. 浏览器插件

浏览器插件可以把小红书、YouTube、知乎、公众号、普通网页、图片、视频、评论和选中文字保存到知识库。

基本使用方式：

1. 在知识库空状态或“设置 → 通用”点击“准备浏览器插件”。
2. 在 Chrome / Edge / Brave 的扩展管理页开启开发者模式，加载应用打开的导出目录。
3. 保持桌面端运行，点击扩展图标打开 side panel，在目标页面执行保存或采集。
4. 知识库会即时刷新，不需要切换页面。

公开内容无需登录 GardenFlow 或绑定平台账号。平台限制的正文、评论或批量内容需要用户在原浏览器页面自行登录或完成验证；GardenFlow 不托管账号凭证，也不会绕过平台验证。

## 12. 空间与数据管理

### 12.1 多空间

- 一个空间是一套相对独立的知识、稿件、媒体、资产、记忆和 GardenFlow 项目。
- 顶部/侧栏空间菜单可创建、重命名、切换和删除空间。
- 默认空间不能删除。
- 删除其他空间前先备份；数据库记录和对应文件目录可能都受影响。

### 12.2 备份

完整备份包括：

- 工作空间根目录，默认 `~/.gardenflow`。
- Electron userData 目录中的 `gardenflow.db`，以及存在时的 `gardenflow.db-wal`、`gardenflow.db-shm`。

备份前真正退出应用。API Key 和 MCP 配置位于数据库中，备份应按敏感文件保护。

### 12.3 移动工作空间

1. 退出应用并备份原目录。
2. 复制整个 workspace 到新位置。
3. 启动应用，在设置中选择新根目录。
4. 检查每个空间的知识、稿件、媒体和 Skills。
5. 对跟踪文件夹、Obsidian 和外部媒体路径重新绑定。

不要只移动 workspace 后删除旧 userData 数据库；会话、任务和设置仍依赖 SQLite。

## 13. 隐私与安全

- API Key 当前保存在本地 SQLite，开源代码未实现操作系统钥匙串加密。
- 不要把 workspace、数据库、日志或诊断包提交到公开仓库。
- 启用代理时保留 `localhost,127.0.0.1,::1` 绕过，避免本地模型和桥接被错误转发。
- 只批准你理解的工具调用，尤其是 shell、写文件、删除和外部发送。
- 浏览器插件请求较多站点和浏览器权限；只从可信构建安装，并在不使用时禁用。
- 本地 daemon 和 bridge 不应监听公网地址，除非另有鉴权、防火墙和审计方案。

## 14. 常见问题

### 为什么官方登录不可用？

开源仓库没有包含生产 `desktop/private/` 功能时，官方登录和会员会降级。使用自定义 AI 源即可运行核心链路。

### 为什么连接测试成功，聊天仍报模型错误？

模型列表接口可用不等于 `/chat/completions`、工具调用、流式输出和附件协议全部兼容。检查模型 ID、协议和当前业务路由，优先使用 OpenAI-compatible 服务测试。

### 为什么图片/视频无法生成？

聊天模型与媒体模型是不同路由。请单独配置图片/视频 Endpoint、Key 和模型，并确认参考素材格式、大小和远程服务能力。

### 为什么切换页面后内容重新加载？

大多数页面默认在切换后卸载，以减少资源占用；正在执行任务的 GardenFlow、选题、自由创作和封面页面会按运行状态保持挂载。

### 为什么自动化没有执行？

确认任务启用、应用仍在运行、系统没有长期休眠、网络和 AI 源可用。先点“立即运行”，再查看后台任务和诊断日志。

### 为什么插件显示未连接？

先在知识库或“设置 → 通用”查看状态。执行“准备浏览器插件”会重新导出扩展并修复 Native Host；随后在浏览器扩展页重新加载扩展。若状态为“平台要求登录”或“需要完成验证”，请回到原网页处理后重试。

### 如何报告问题？

在标题栏使用“反馈问题”，或到 `设置 → 通用 → 诊断与日志` 查看、导出诊断包。提交前检查包中是否包含路径、模型名或其他不希望共享的信息。
