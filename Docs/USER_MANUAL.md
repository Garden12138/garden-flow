# GardenFlow 使用手册

[第一次使用？从公开示例完成一篇介绍稿](./FIRST_CREATION.md)。不需要先安装浏览器扩展或配置全部模型。

## 1. 第一次启动

GardenFlow 启动后会进入默认空间。先完成三项设置：

1. 在“设置 → 通用”确认 workspace。
2. 在“设置 → AI 供应商”添加文本供应商，在能力路由中选择供应商和模型，然后保存设置。
3. 如需网页采集，在“设置 → 隐私与诊断 → 浏览器插件”点击“准备插件”和“打开插件目录”，在浏览器加载导出的扩展，并确认连接状态。

AI 未配置时，本地素材、知识、稿件和媒体管理仍可使用；需要模型的按钮会给出配置提示。

## 2. 空间与工作台

空间用于隔离不同账号、品牌或项目的内容。侧栏底部可以创建、切换、重命名和删除空间。空间创建不受账号或权益限制。

主工作台展示知识、资产、媒体、稿件和审批统计，以及最近工作。流程轨道对应“素材 → 灵感 → 创作 → 生成 → 计划”，可直接进入下一阶段。

## 3. 采集与知识

### 浏览器采集

安装包用户无需构建源码：先在应用内准备插件，在浏览器扩展管理页开启开发者模式并加载导出的目录。完整步骤见[插件安装](./FIRST_CREATION.md#需要采集网页时再装扩展)。“已准备”表示扩展和 Native Host 已准备；“已连接”还需要浏览器加载扩展并握手。

1. 在 Chrome、Edge 或 Brave 打开目标页面。
2. 打开 GardenFlow 扩展侧栏。
3. 选择结构化采集或通用网页采集。
4. 预览标题、来源和媒体数量后保存。
5. 回到知识库查看新条目与来源链接。

京东商品详情页使用单独的商品流程：在页面选好当前规格，打开扩展侧栏并点击“预览商品资料”；核对商品名、规格、价格和图片数量后，再点击“确认保存到资产库”。商品会进入“资产库 → 商品”，未选择品牌时暂存在“待整理商品”。重复采集同一商品会增加一条带时间和规格的来源快照，并保留用户已经编辑的商品名称、描述和创作资料。

预览会显示品牌、店铺、当前规格、价格快照和完整商品参数，主图与详情图可通过缩略图切换。若参数或详情图片缺失，先在京东展开对应内容，再点击“重新识别”。旧版保存到资料库的商品会使用商品预览，过滤小尺寸徽标，并将旧采集原文折叠；重新采集一次后，旧记录预览也会读取对应的新版商品资料。

扩展不读取浏览器 Cookie。只有用户触发的采集内容会通过本机 Native Messaging 进入 GardenFlow。

### 本地资料

知识库支持导入公开仓库当前 UI 列出的文件类型。导入后可查看索引状态、全文搜索、向量检索和来源详情。Embedding 未配置时，全文与元数据检索仍可使用。

## 4. 灵感与选题

灵感工作台把已采集素材、评论洞察与选题候选放在同一视图：

1. 选择来源范围或素材集合。
2. 运行“灵感漫步”或评论洞察。
3. 审查候选标题、方向、证据和评分。
4. 放弃不合适的候选，保留可执行方向。
5. 点击“AI 创作”把选题和引用带入创作工作台。

生成内容前应核对来源事实、时间和版权。模型输出不是事实保证。

## 5. AI 创作

创作工作台支持多会话、引用、附件、任务时间线和结构化稿件：

- 用 `#` 或界面选择器加入知识来源。
- 明确目标、受众、交付形式和约束。
- 在时间线查看模型与工具调用状态。
- 对文件写入、发布等高影响操作审查确认。
- 把最终结果保存为文章、脚本、小红书图文或其他当前支持的稿件类型。

在创作页用 `@` 选择商品，把商品事实、来源快照、已采集 SKU 和原始商品图作为创作引用，再输入商品介绍、场景种草或选购说明等具体要求。价格按采集时间作为快照引用；AI 提炼内容不会自动写回商品事实。

若收到额度或鉴权错误，打开 AI 设置检查实际使用的供应商、Endpoint、Key 和模型。GardenFlow 不提供积分或统一结算。

### 商品图片视频

在创作中用 `@` 选择一个商品并说明视频要求。系统先验证图片理解，再展示分镜、真实缩略图、AI 动效与旁白任务数；确认后才创建工程和提交生成任务。没有可用参考图视频模型时默认用五个原图动效镜头组成 15 秒竖版视频，仍可编辑、导出和准备发布。

只用原图制作视频时，可在“设置 → 视频服务”取消“启用视频生成”并保存。供应商、模型和密钥配置会保留，重新启用即可恢复。关闭时不会提交新的视频生成请求，已有工程仍可编辑、预览和导出。

图片理解失败时，错误提示会说明原因，可点击“重试图片理解”使用当前选中的模型重新执行。校验码错误或图片缺失不会被自动放过。商品资料、SKU、图片或重新采集发生变化后，待确认卡立即失效；点击“按最新资料重新规划”会沿用原始要求并重新等待确认。商品已删除时须重新选择商品。已经创建的工程保留独立素材快照。

商品工程的旁白和 BGM 独立控制，默认音量分别为 100% 和 20%。旁白超出镜头时长会提示冲突，并停止该段播放；延长对应镜头后恢复，不自动裁剪。修改旁白文案会标记旧声音过期，点击生成才重新合成；也可以替换录音或撤销。

需要无旁白视频时，在创作要求中明确说明。分镜提案会关闭自动旁白，确认卡显示 0 段语音任务，字幕仍保留；确认及重启不会自动调用 TTS。创建工程后仍可手动编辑旁白文案并点击生成。

### 制作独立抖音短视频版本

在商品视频工作台点击“创建抖音版本”。系统复制当前分镜、素材和双音轨，打开独立工程；再次点击会打开已有版本，只有“再复制一版”才另外建立工程。抖音版本的镜头和文案修改不会写回来源工程。工程画面上的右侧和底部阴影是安全区示意，最终效果仍应在抖音发布页核对。

点击“抖音稿件”编辑内部标题、发布描述、话题和封面素材。修改镜头、字幕或音轨后，须在该版本重新“保存 MP4 到资产库”。发布时安装并重新加载应用导出的新版平台发布插件，在已登录的抖音创作者中心只保留一个视频上传页；通过“准备抖音发布”绑定浏览器、读取目标账号并创建确认卡。自选图片封面会从该工程素材生成居中裁剪的竖封面（3:4）和横封面（4:3），确认卡展示实际 MP4、两张封面、文案和账号；默认封面保留平台原行为。可先点击“上传到页面供核对（不发布）”，核对平台保存的封面后再点击最终发布确认。未点击发布确认不会提交；上传、封面保存或回读失败时停止，不能忽略封面选择。账号无法识别、页面已有其他任务的草稿或成片已过期时会阻断。旧插件缺少图片封面能力时需要更新插件。修改稿件、封面素材或工程后须重新准备确认；已发布的旧任务不受影响。

上传页提示“继续编辑上次未发布的视频”时，也视为已有草稿，即使没有视频预览或描述。请先在抖音页面核对该草稿；插件不会代为丢弃，也不会用新视频覆盖它。

封面步骤失败后，原任务保留视频和文案。如果抖音封面编辑器仍打开，先核对并关闭弹窗，再在原确认卡点击“上传到页面供核对（不发布）”重试。恢复期间标题、文案或视频变化会阻断，需重新核对当前版本。

已有上传图片时，插件使用封面上传器的替换控件；保存前等待图片处理，保存后核对实际封面。页面在最终准备期间再次更新封面时，会重新核对两张图片；无法确认与所选封面一致时停止，原草稿保留。发布插件弹窗可查看媒体、文案、封面及页面校验的具体检查结果。自选图片双封面的真实自动上传、回读及重启恢复已验证，结果见 `Docs/DOUYIN_STAGE3_ACCEPTANCE.md`；未通过回读的任务不能提交。

平台返回“审核中”时只记为已提交待审核。若结果未知，先在抖音作品管理核对；看到该任务的作品已发布，可在确认卡勾选“已发布”并记录人工核实结果，原浏览器回到空白视频发布页后任务标记完成。明确核实未发布时，才使用“已核实未发布，恢复发布页”重新准备；不要直接重复点击发布。

京东和小红书自动采集报告进入各空间的专用会话，可从“计划 → 自动化”的“查看采集报告”进入。发布后的确认卡显示实际回执；遇到结果未知先检查平台笔记管理，不直接重发。

## 6. 图片、视频与音频

生成工作台按媒体类型保存独立配置。提交任务前会显示当前供应商、模型和能力约束。

- 图片：提示词、参考图、尺寸、质量和数量。
- 视频：文生视频、图生视频、首尾帧、续写或音频驱动，具体取决于预设能力。
- 音频：语音合成、音色、转录与相关模型能力。
- 封面：模板图、标题层级、风格和生成结果。

结果成功写入真实文件后才进入媒体库。媒体库可以预览、定位文件、复用为参考素材或绑定到结构化稿件槽位。

`new-api-aliyun` 和 `new-api-minimax` 必须在视频设置中显式选择。若 Endpoint、Key 或模型缺失，任务会直接显示可修复错误。

## 7. 自动化

自动化页包含定时任务、内置采集任务和运行记录：

1. 创建任务并选择计划模式。
2. 审查目标、作用空间和需要的工具。
3. 保存后可启停、立即运行或删除。
4. 在通知中心和任务卡查看进度、失败原因与产物。

内置的“京东商品自动采集”按关键词工作。可配置一个或多个采集关键词，任务每天轮换一个关键词，通过插件在京东页面搜索、读取商品卡片，并逐个打开商品页复用侧栏保存链路，把商品字段、商品图、评论和买家秀图片保存为来源快照。商品页打开期间，侧栏会显示“自动任务采集中”；单个商品入库成功后由插件在同一次调用中关闭详情页，整轮结束后自动关闭本任务创建的搜索页。评论标签留空时采集好评、中评、差评，也可指定“图/视频”“回头客”等页面可见标签；“每个标签评论数”可设置 1–50，默认 5 条。用户评论和商家回复会配对保存并分别展示。任务按新入库商品数计算单轮目标，重复复采不占新增配额。“保守”节奏会在搜索前等待、降低搜索与评论滚动频率，并让商品页停留 10–16 秒、商品之间随机等待 20–35 秒；检测到安全验证、访问频繁或连续两个商品失败时立即结束本轮。该任务默认关闭，填写关键词且插件桥接就绪后才能开启；单个商品详情仍可在页面侧栏直接保存，并可选择限定数量或尽量采集更多。

资产库中的商品支持硬删除。可在商品列表点击删除图标，或进入商品详情后点击“硬删除”；确认后会永久删除商品资料、来源快照、SKU、评论、详情页、AI 索引记录和关联的本地图片文件，无法恢复。

发布、持久化写入和其他高影响动作仍受审批策略约束。运维人员可用 `GARDENFLOW_HOLD_AUTOMATION=1` 暂停后台调度。

## 8. 数据与隐私

- workspace 与 SQLite 数据默认在本机。
- API Key 只用于请求所选供应商。
- GardenFlow 不包含使用分析或自动诊断上传。
- 桌面诊断和扩展诊断都有数量上限，仅由用户手动导出。
- 导出报告会移除 Cookie、Token、密钥、网页正文、Data URI 和绝对路径；发送前仍应人工复核。

在“设置 → 隐私与诊断”可以打开日志目录或导出本地诊断包。

## 9. 常见问题

### AI 功能不可用

确认路由不是 `disabled`，供应商已启用，Endpoint、模型和 Key 完整；本地服务还要确认进程正在监听。

### 模型列表能加载，但对话失败

模型列表接口与流式对话、工具调用、视觉附件可能不是同一能力。核对协议类型和模型支持范围，并用最小纯文本请求验证。

### 浏览器扩展未连接

确认浏览器加载的是应用导出的目录。在“设置 → 隐私与诊断 → 浏览器插件”再次执行“准备插件”，打开插件目录核对位置，再重新加载扩展并保持 GardenFlow 打开。知识库也提供“准备浏览器插件”入口。准备完成后仍需检查连接状态；首次创作的本地文件路径不依赖扩展。

### 媒体任务没有结果

查看任务错误、供应商预设、模型能力和输入文件格式。只有返回真实媒体文件的任务才会登记为成功。

### 如何备份

退出 GardenFlow 后备份当前 `gardenflow.db` 和完整 workspace。详见 [本地开发与部署](./LOCAL_DEPLOYMENT.md)。
