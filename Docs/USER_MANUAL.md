# GardenFlow 使用手册

[第一次使用？从公开示例完成一篇介绍稿](./FIRST_CREATION.md)。不需要先安装浏览器扩展或配置全部模型。

## 1. 第一次启动

GardenFlow 启动后会进入默认空间。先完成三项设置：

1. 在“设置 → 通用”确认 workspace。
2. 在“设置 → AI 供应商”添加文本供应商，在能力路由中选择供应商和模型，然后保存设置。
3. 如需网页采集，在“设置 → 隐私与诊断 → 浏览器插件”点击“准备插件”和“打开插件目录”，在浏览器加载导出的扩展，并确认连接状态。

AI 未配置时，本地素材、知识、稿件和媒体管理仍可使用；需要模型的按钮会给出配置提示。

## 2. 空间与工作台

空间用于隔离不同账号、品牌或项目的内容。侧栏底部可以创建、切换、重命名和删除空间。空间创建不受账号或权益限制。

主工作台展示知识、资产、媒体、稿件和审批统计，以及最近工作。流程轨道对应“素材 → 灵感 → 创作 → 生成 → 计划”，可直接进入下一阶段。

## 3. 采集与知识

### 浏览器采集

安装包用户无需构建源码：先在应用内准备插件，在浏览器扩展管理页开启开发者模式并加载导出的目录。完整步骤见[插件安装](./FIRST_CREATION.md#需要采集网页时再装扩展)。“已准备”表示扩展和 Native Host 已准备；“已连接”还需要浏览器加载扩展并握手。

1. 在 Chrome、Edge 或 Brave 打开目标页面。
2. 打开 GardenFlow 扩展侧栏。
3. 选择结构化采集或通用网页采集。
4. 预览标题、来源和媒体数量后保存。
5. 回到知识库查看新条目与来源链接。

京东、淘宝和天猫桌面商品详情页使用商品采集流程：在页面选好当前规格，打开扩展侧栏并点击“预览商品资料”；核对商品名、规格、价格和图片数量后，再点击“确认保存到资产库”。商品会进入“资产库 → 商品”，未选择品牌时暂存在“待整理商品”。重复采集同一商品会增加一条带时间和规格的来源快照，并保留用户已经编辑的商品名称、描述和创作资料。

预览会显示品牌、店铺、当前规格、价格快照和完整商品参数，主图与详情图可通过缩略图切换。若参数或详情图片缺失，先在来源页面展开对应内容，再点击“重新识别”。旧版保存到资料库的商品会使用商品预览，过滤小尺寸徽标，并将旧采集原文折叠；重新采集一次后，旧记录预览也会读取对应的新版商品资料。

淘宝与天猫分别记录为“淘宝”和“天猫”来源。插件只读取当前选中的规格和页面可见价格；缺失项会明确显示，不会从未选规格或优惠信息推测价格。淘宝／天猫评论默认采集当前列表 5 条；可勾选页面真实标签，并分别设置每个标签 1–50 条。采集采用有限滚动与等待，无新增时结束；遇到登录、安全验证或访问限制会停止评论读取，已读取的商品资料和评论仍可保存，同时提示评论未完成。买家正文、商家回复与评论图片分别保存，主题标签不会自动被当作好评、中评或差评。

淘宝／天猫会先展开完整评价列表。已经打开但仍在加载的评价弹窗会继续等待；入口首次点击没有响应时最多再试一次，总等待上限为 6 秒。已经选中的标签直接读取，切换其他标签则等待实际评论列表更新；标签颜色变化本身不算加载成功。未达到请求条数或仍未加载时会保留已读内容并说明原因。

若标签明确显示只有 0、1、2 等准确条数，会保留用户设置的采样配额，并在资产库显示“页面共 N 条”；已取得这些评论时不再提示读取不足。带“+”或“万”等概数不能作为采完的依据，评论图片未就绪和访问限制仍会提示。

重采图片会先校验并复用同一平台、同一商品或评论、相同图片地址的已有采集文件。新图片最多同时下载 4 张，临时网络错误最多重试一次，整批网络下载上限为 60 秒；登录拒绝、限流、非法跳转或无效图片不会反复重试。失败时保留已成功读取的资料与图片，并显示原因。不会借用另一商品的图片，历史快照继续保留。

规格文字异常时，会优先使用同一选项中可正常读取的文字；必要时仅从与当前商品及已选 SKU 完整匹配的属性资料恢复。无法恢复则显示“当前规格文字异常”，不猜测缺失字符。取得正常文字后重采，可修正有明确旧采集记录的乱码 SKU；用户编辑和历史快照保留。

淘宝／天猫提供关键词、批量和定时采集任务，入口为“计划 → 自动化 → 淘宝商品自动采集／天猫商品自动采集”。自动采集的配置、报告及当前标签清理限制见下文“自动化”。

在“资产库 → 商品”详情可按时间和规格切换采集记录。同一平台同一商品重采会追加快照；不同平台的相同商品始终是不同商品，各自保留素材、SKU、编辑资料和创作引用。

商品详情的“AI 查找同款”使用设置中的文本模型，按名称、品牌、明确型号及规格给出最多 3 个候选和依据。检查候选后点击“确认关联”，才建立同款关系。模型未配置或请求失败时，页面显示原因，也可通过“手动选择商品”确认关联。确认前若任一商品资料更新，需要重新查找；同款卡片可跳转另一商品，也可“解除关联”。删除商品会清理相关关系，另一商品继续保留。关联和解除关联不改变商品资料版本，也不影响已确认分镜或已有工程；`@商品` 只引用被选商品自己的资料和素材。

扩展不读取浏览器 Cookie。只有用户触发的采集内容会通过本机 Native Messaging 进入 GardenFlow。

### 本地资料

知识库支持导入公开仓库当前 UI 列出的文件类型。导入后可查看索引状态、全文搜索、向量检索和来源详情。Embedding 未配置时，全文与元数据检索仍可使用。

## 4. 灵感与选题

灵感工作台把已采集素材、评论洞察与选题候选放在同一视图：

1. 选择来源范围或素材集合。
2. 运行“灵感漫步”或评论洞察。
3. 审查候选标题、方向、证据和评分。
4. 放弃不合适的候选，保留可执行方向。
5. 点击“AI 创作”把选题和引用带入创作工作台。

生成内容前应核对来源事实、时间和版权。模型输出不是事实保证。

## 5. AI 创作

创作工作台支持多会话、引用、附件、任务时间线和结构化稿件：

- 用 `#` 或界面选择器加入知识来源。
- 明确目标、受众、交付形式和约束。
- 在时间线查看模型与工具调用状态。
- 对文件写入、发布等高影响操作审查确认。
- 把最终结果保存为文章、脚本、小红书图文或其他当前支持的稿件类型。

在创作页用 `@` 选择商品，把商品事实、来源快照、已采集 SKU 和原始商品图作为创作引用，再输入商品介绍、场景种草或选购说明等具体要求。价格按采集时间作为快照引用；AI 提炼内容不会自动写回商品事实。

若收到额度或鉴权错误，打开 AI 设置检查实际使用的供应商、Endpoint、Key 和模型。GardenFlow 不提供积分或统一结算。

### 商品视频、混剪与套图

用 `@` 选择已入库商品，再点击“商品创作”，先选择平台、内容形式、编排模式、语言及规格，确认选择后才发起规划。取消不会请求模型或创建工程。小红书、抖音和 TikTok 支持视频，小红书还支持套图；抖音／TikTok 套图显示待适配。完整操作见[商品创作与发布](./PRODUCT_CREATION.md)。

视频默认 15 秒、9:16、1080×1920、30fps，可用商品原图动效或选定的已有片段混剪；小红书另支持 16:9。套图默认 5 张含封面，固定 3:4、1440×1920 PNG。TikTok 默认英文和 `International` 市场，创作前可修改。

核对方案中的商品规格、真实缩略图、分镜／页面及文案，确认后创建独立工程。待确认期间商品资料更新会使旧方案失效，可“按最新资料重新规划”；已创建工程保留独立素材快照。默认流程复用原图或已有视频，不自动提交付费媒体生成；需要图片、视频或语音时，通过对应确认入口核对模型、素材和计费提示。

每个工程版本有独立编辑对话，原创作会话的“继续编辑此作品”进入同一对话。发送前自动保存手动输入；保存失败、冲突或模型等待期间出现新编辑时，保留输入并阻断旧结果覆盖。手动和对话修改共用最近 20 次撤销历史，关闭重开后可继续编辑。

视频可改字幕、旁白、时长、顺序、素材、截取、适配、原图动效及原音／旁白／BGM 音量。修改旁白会使旧配音过期，不自动合成；导出前需要重新生成或移除过期配音，没有配音素材时可静音导出。旁白超出镜头时长时应延长镜头或调整文案。

套图可逐页改文字、图片、裁切、模板、配色和字号，封面固定第一张，内容页可增删和排序。编辑最多 20 张；图片发布最多 18 张，是应用限制。标题和文案始终是本地可编辑图层，AI 画面按页单独确认生成。

视频导出 MP4 并入库；套图支持单页 PNG、整套目录和 ZIP。画面或声音修改后须更新导出，套图只重渲染受影响页面。仅发布文案或设置变化保留可复用媒体，但旧发布确认仍会失效。迟到的过期生成结果保留为素材，不覆盖当前镜头或页面。

### 统一发布管理

工程工作台的“准备发布”和“计划 → 发布”共用发布任务，集中展示平台、真实账号、浏览器、插件连接、页面状态、待处理任务和历史。准备需要当前工程已保存、成片／整套图片有效、目标绑定明确和设置完整；失败时保留输入，不自动渲染或生成媒体。

准备只创建本地任务并展示内容。点击“上传到页面供核对”后才上传并回读媒体、文案和设置；核对通过后，再点击最终发布按钮才提交。对话中的自然语言不能代替这两次按钮确认。编辑、换账号、换浏览器或手动改变页面内容会使旧确认失效，插件不会覆盖其他任务的草稿。

小红书套图按封面和页面顺序上传，相同图片也保留各自位置。19／20 张工程需用户减少页数后才能准备发布。TikTok 所有发布设置需要用户完整选择。上传失败可核对后重试，已提交、审核中或结果未知的任务先核实，不自动重发；没有可信作品链接时明确显示缺失。

### 制作独立抖音短视频版本

在商品视频工作台点击“创建抖音版本”。系统复制当前分镜、素材和双音轨，打开独立工程；再次点击会打开已有版本，只有“再复制一版”才另外建立工程。抖音版本的镜头和文案修改不会写回来源工程。工程画面上的右侧和底部阴影是安全区示意，最终效果仍应在抖音发布页核对。

点击“抖音稿件”编辑内部标题、发布描述、话题和封面素材。修改镜头、字幕或音轨后，须在该版本重新“保存 MP4 到资产库”。发布时安装并重新加载应用导出的新版平台发布插件，在已登录的抖音创作者中心只保留一个视频上传页；通过“准备抖音发布”绑定浏览器、读取目标账号并创建确认卡。自选图片封面会从该工程素材生成居中裁剪的竖封面（3:4）和横封面（4:3），确认卡展示实际 MP4、两张封面、文案和账号；默认封面保留平台原行为。可先点击“上传到页面供核对（不发布）”，核对平台保存的封面后再点击最终发布确认。未点击发布确认不会提交；上传、封面保存或回读失败时停止，不能忽略封面选择。账号无法识别、页面已有其他任务的草稿或成片已过期时会阻断。旧插件缺少图片封面能力时需要更新插件。修改稿件、封面素材或工程后须重新准备确认；已发布的旧任务不受影响。

上传页提示“继续编辑上次未发布的视频”时，也视为已有草稿，即使没有视频预览或描述。请先在抖音页面核对该草稿；插件不会代为丢弃，也不会用新视频覆盖它。

封面步骤失败后，原任务保留视频和文案。如果抖音封面编辑器仍打开，先核对并关闭弹窗，再在原确认卡点击“上传到页面供核对（不发布）”重试。恢复期间标题、文案或视频变化会阻断，需重新核对当前版本。

已有上传图片时，插件使用封面上传器的替换控件；保存前等待图片处理，保存后核对实际封面。页面在最终准备期间再次更新封面时，会重新核对两张图片；无法确认与所选封面一致时停止，原草稿保留。发布插件弹窗可查看媒体、文案、封面及页面校验的具体检查结果。未通过回读的任务不能提交；统一流程见[商品创作与发布](./PRODUCT_CREATION.md)。

平台返回“审核中”时只记为已提交待审核。若结果未知，先在抖音作品管理核对；看到该任务的作品已发布，可在确认卡勾选“已发布”并记录人工核实结果，原浏览器回到空白视频发布页后任务标记完成。明确核实未发布时，才使用“已核实未发布，恢复发布页”重新准备；不要直接重复点击发布。

京东和小红书自动采集报告进入各空间的专用会话，可从“计划 → 自动化”的“查看采集报告”进入。发布后的确认卡显示实际回执；遇到结果未知先检查平台笔记管理，不直接重发。

### 制作国际版 TikTok 视频

在商品视频工作台点击“创建 TikTok 版本”，打开独立副本。镜头、素材、字幕、旁白、音乐和文案均可独立修改；再次从来源点击会打开已有版本，“再复制一版”才另建。TikTok 指国际版，国内抖音入口继续单独保留。

点击“TikTok · 文案与语言”，设置语言代码（如 `en`、`ja`）和目标市场，编辑标题、发布文案及话题。标题用于内部管理，TikTok 页面填写文案和话题，合计最多 4000 字符。“AI 语言建议”使用已配置的文本模型，依据已保存稿件展示逐镜头字幕与旁白的前后对照；点击“确认应用文案、字幕和旁白文字”才写入。应用不会自动生成视频或语音，旁白文字变化会把旧音频标为过期。无模型或请求失败时可手动编辑。

修改画面、字幕或声音后，须在这个副本重新“保存 MP4 到资产库”。保存明确选择的可见范围、评论、内容复用、Remix、商业披露、AI 标记和年龄限制；不完整设置不能准备发布。AI 建议过期、工程或版本变化时重新生成，重开应用后未应用的建议需重新生成。

重新加载最新平台发布插件，登录 TikTok Studio，保留一个视频上传页。点击“检查发布浏览器”绑定实例，再“准备已保存版本的发布”。确认卡显示成片、真实账号、文案与设置。“上传并填入编辑页”用于核对，未点击“确认发布到 TikTok”不会点击 Post。已有其他草稿、错账号、验证或控件读回不一致会停止，插件不会自动丢弃草稿或接受条款。

Post 后若显示“提交结果待核实”，请先在 TikTok Posts 核对该账号、成片和文案，原账号回到空白视频上传页后，在桌面记录核实已发布；明确未发布时才关闭旧任务并重新准备。插件不会自动重发。已核实发布的任务可在浏览器打开 Studio Posts，点击“读取已发布作品回执”，保存作品链接、平台显示的时间、时长及可见范围；账号、文案或可见范围不一致、同文案候选不唯一时会停止，已保存的回执不会自动换成另一作品。当前真实审核／拒绝分支尚缺样本，验证范围见[路线图](../ROADMAP.md)。

## 6. 图片、视频与音频

生成工作台按媒体类型保存独立配置。提交任务前会显示当前供应商、模型和能力约束。

- 图片：提示词、参考图、尺寸、质量和数量。
- 视频：文生视频、图生视频、首尾帧、续写或音频驱动，具体取决于预设能力。
- 音频：语音合成、音色、转录与相关模型能力。
- 封面：模板图、标题层级、风格和生成结果。

结果成功写入真实文件后才进入媒体库。媒体库可以预览、定位文件、复用为参考素材或绑定到结构化稿件槽位。

`new-api-aliyun` 和 `new-api-minimax` 必须在视频设置中显式选择。若 Endpoint、Key 或模型缺失，任务会直接显示可修复错误。

## 7. 自动化

自动化页包含定时任务、内置采集任务和运行记录：

1. 创建任务并选择计划模式。
2. 审查目标、作用空间和需要的工具。
3. 保存后可启停、立即运行或删除。
4. 在通知中心和任务卡查看进度、失败原因与产物。

内置的“京东商品自动采集”按关键词工作。可配置一个或多个采集关键词，任务每天轮换一个关键词，通过插件在京东页面搜索、读取商品卡片，并逐个打开商品页复用侧栏保存链路，把商品字段、商品图、评论和买家秀图片保存为来源快照。商品页打开期间，侧栏会显示“自动任务采集中”；单个商品入库成功后由插件在同一次调用中关闭详情页；整轮搜索标签清理仍有授权衔接缺口，请按下文说明检查遗留标签。评论标签留空时采集好评、中评、差评，也可指定“图/视频”“回头客”等页面可见标签；“每个标签评论数”可设置 1–50，默认 5 条。用户评论和商家回复会配对保存并分别展示。任务按新入库商品数计算单轮目标，重复复采不占新增配额。“保守”节奏会在搜索前等待、降低搜索与评论滚动频率，并让商品页停留 10–16 秒、商品之间随机等待 20–35 秒；检测到安全验证、访问频繁或连续两个商品失败时立即结束本轮。该任务默认关闭，填写关键词且插件桥接就绪后才能开启；单个商品详情仍可在页面侧栏直接保存，并可选择限定数量或尽量采集更多。

“淘宝商品自动采集”和“天猫商品自动采集”使用同一批量调度流程，分别从对应首页搜索。先更新桌面端及其配套采集插件，打开已登录浏览器，在“计划 → 自动化”填写关键词、每轮目标新增商品数（1–20，默认 5）、评论配置及时间。配置就绪后可直接点“立即运行”执行一轮，定时开关保持原状态；打开开关后才会按设置时间自动执行。自动采集不调用文本、图片或视频生成模型；图片下载和入库复用手动采集链路。桌面端与浏览器须保持运行，休眠或退出时不会继续采集。

淘宝／天猫评论标签留空时默认采当前评价列表 5 条；指定标签时只使用页面真实存在的标签，每个标签 1–50 条，不推断好中差。搜索结果可同时包含淘宝和天猫详情页，来源以实际详情页为准；不同平台商品独立保存，同平台复采追加快照并保留编辑资料和本地素材。复采不占新增配额，搜索补读最多 2 次，尝试商品数有上限；不足目标时报告说明实际保存数。

天猫搜索商品可能跳到 `chaoshi.detail.tmall.com` 的天猫超市详情。新版支持该地址，商品编号一致时继续采集并归为天猫来源；与普通天猫详情的相同编号复采仍追加同一商品快照。若旧版提示该域名与搜索卡片不一致，更新并重启桌面端、重新加载采集插件后再运行。

登录、验证、限流会立即停止本轮；若评论触发限制，已读商品资料仍保存，任务报告列出评论未完成原因。淘宝／天猫详情商品编号与搜索卡片不一致时，跳过该件并在本轮尝试上限内继续补足新增目标，不保存另一件商品。报告显示搜索编号、实际页面编号及来源；同编号在淘宝／天猫之间正常跳转可继续采集。连续两个其他采集错误会提前停止，并显示具体错误，不将其称为站点风控。已入库或复采但新增目标不足时，任务卡显示“上次部分完成”，成功结果保留。任务仅应清理自己创建的标签，不操作原有页面。当前搜索标签关闭的授权衔接尚未完成，可能留下本次任务的搜索标签；检查报告后手动关闭这些遗留任务标签，保留用户原有页面。商品入库固定在任务启动时的空间，执行中切换空间不改变本轮保存位置。每项任务在每个空间都有独立采集报告，可从任务卡“查看采集报告”打开，不改变当前创作确认卡。用户在浏览器完成登录或验证后，可以重新点“立即运行”。

资产库中的商品支持硬删除。可在商品列表点击删除图标，或进入商品详情后点击“硬删除”；确认后会永久删除商品资料、来源快照、SKU、评论、详情页、AI 索引记录和关联的本地图片文件，无法恢复。

在“计划 → 发布”可分别开启小红书、抖音和 TikTok 的“完成后询问是否发布”，抖音／TikTok 默认关闭，未连接插件也可开启询问。最新完整 MP4 或整套目录／ZIP 导出后，询问进入该版本编辑对话；单页 PNG、失败和重复内容不触发。选择“暂不发布”后同一内容不再询问，仍可手动准备发布。开关只影响之后的完成事件；询问不调用模型、不上传、不提交。

发布、持久化写入和其他高影响动作仍受审批策略约束。运维人员可用 `GARDENFLOW_HOLD_AUTOMATION=1` 暂停后台调度。

## 8. 数据与隐私

- workspace 与 SQLite 数据默认在本机。
- API Key 只用于请求所选供应商。
- GardenFlow 不包含使用分析或自动诊断上传。
- 桌面诊断和扩展诊断都有数量上限，仅由用户手动导出。
- 导出报告会移除 Cookie、Token、密钥、网页正文、Data URI 和绝对路径；发送前仍应人工复核。

在“设置 → 隐私与诊断”可以打开日志目录或导出本地诊断包。

## 9. 常见问题

### AI 功能不可用

确认路由不是 `disabled`，供应商已启用，Endpoint、模型和 Key 完整；本地服务还要确认进程正在监听。

### 模型列表能加载，但对话失败

模型列表接口与流式对话、工具调用、视觉附件可能不是同一能力。核对协议类型和模型支持范围，并用最小纯文本请求验证。

### 浏览器扩展未连接

确认浏览器加载的是应用导出的目录。在“设置 → 隐私与诊断 → 浏览器插件”再次执行“准备插件”，打开插件目录核对位置，再重新加载扩展并保持 GardenFlow 打开。知识库也提供“准备浏览器插件”入口。准备完成后仍需检查连接状态；首次创作的本地文件路径不依赖扩展。

### 商品页面已经显示，但插件读不到商品名称

淘宝／天猫采集会先读取页面商品标题和与当前商品匹配的结构化资料，最多等待 3 秒，再尝试网页标题元数据。通用的“商品详情”、登录页标题及指向其他商品的元数据不会当作商品名称保存。地址中的 `skuId` 或推荐追踪价格也不会替代当前选中的规格、价格。

新版淘宝详情页会读取实际选中的颜色、尺码及页面高亮价格；“平台加补后”等价格说明会一并保留。图片按当前商品的图集和图文详情采集并去重。评论区提供“查看全部评价”时，插件会先点击并等待完整列表正文加载，再读取标签、按默认 5 条或所选数量采样；已经展开的列表会直接复用。不会把详情页内嵌的 2 条评论视为完整列表。若完整列表未加载，会明确提示并保留已经读取的评论；遇到登录、验证或限流会停止评论操作。主题标签的数量不会当成已读取的评论数。

需要保存网页供资料核对时，先确认商品编号和当前规格与目标采集快照相同，再展开“查看全部评价”，滚动详情及评价列表并等待图片显示。含“追评”等标签的采样应在选择该标签后另存一份网页；文件名可注明商品编号、规格及标签。使用浏览器“网页，全部”保存，并同时保留 HTML 和配套资源文件夹。保存时仍未加载的图片或未打开的标签内容，需要补充相应页面后才能核对。

商品编号与 SKU 编号分别显示，评论日期与页面“已购”规格也分别保存。评论正文达到数量后，插件会将待采评论图片逐张滚入视野，触发懒加载并有限重试，也支持横向图片列表。每个标签内每张图片最多尝试两次，每个标签的额外图片等待最多 15 秒、整次最多 30 秒；稍后在其他标签补齐的图片不会继续显示旧的缺图警告。已知的“图片/视频加载中”占位图不会保存为评论图片，达到上限仍缺失时会提示未完成。采集会保留读取到的初评、追评正文和商家回复，并排除详情中的公益等平台模块；真实追评是否完整仍需与展开后的页面核对。

更新应用后重新“准备插件”并在 Chrome 重载扩展，再对已有问题商品重新识别、保存。重采会追加新快照，替换非手工编辑的旧采集描述，并将已确认的公益图标从新建创作素材中排除；旧快照、文件和已有工程继续保留，用户手工编辑不被覆盖。旧快照不会自动变成新采集结果。

如果提示“已识别商品……但未读取到商品名称”，说明地址中的商品标识已读取，但名称仍缺失。更新应用后执行“准备插件”，在 Chrome 扩展管理中重新加载 GardenFlow 采集插件，再重新打开插件预览。开发环境也可直接加载 `Plugin/dist/extension/` 构建目录。仍失败时记录完整错误和商品链接，作为页面适配问题继续排查；不要把浏览器工具的权限错误与此采集错误混为一谈。

若已出现名称但提示“商品主体未识别”，说明规格、价格、图片、参数和详情仍未读到；“仅保存已识别资料”不会自动补齐这些信息。评论区显示未读取到正文，也不等于商品没有评论，需要继续核对页面适配或加载状态。

### 媒体任务没有结果

查看任务错误、供应商预设、模型能力和输入文件格式。只有返回真实媒体文件的任务才会登记为成功。

退出 GardenFlow 后备份当前 `gardenflow.db` 和完整 workspace。详见 [本地开发与部署](./LOCAL_DEPLOYMENT.md)。
