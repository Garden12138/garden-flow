# GardenFlow 使用手册

## 1. 第一次启动

GardenFlow 启动后会进入默认空间。先完成三项设置：

1. 在“设置 → 常规”确认 workspace。
2. 在“设置 → AI 服务”添加至少一个供应商并选择文本模型。
3. 如需网页采集，在“设置 → 浏览器插件”准备 Native Host，并确认扩展显示已连接。

AI 未配置时，本地素材、知识、稿件和媒体管理仍可使用；需要模型的按钮会给出配置提示。

## 2. 空间与工作台

空间用于隔离不同账号、品牌或项目的内容。侧栏底部可以创建、切换、重命名和删除空间。空间创建不受账号或权益限制。

主工作台展示知识、资产、媒体、稿件和审批统计，以及最近工作。流程轨道对应“素材 → 灵感 → 创作 → 生成 → 计划”，可直接进入下一阶段。

## 3. 采集与知识

### 浏览器采集

1. 在 Chrome、Edge 或 Brave 打开目标页面。
2. 打开 GardenFlow 扩展侧栏。
3. 选择结构化采集或通用网页采集。
4. 预览标题、来源和媒体数量后保存。
5. 回到知识库查看新条目与来源链接。

扩展不读取浏览器 Cookie。只有用户触发的采集内容会通过本机 Native Messaging 进入 GardenFlow。

### 本地资料

知识库支持导入公开仓库当前 UI 列出的文件类型。导入后可查看索引状态、全文搜索、向量检索和来源详情。Embedding 未配置时，全文与元数据检索仍可使用。

## 4. 灵感与选题

灵感工作台把已采集素材、评论洞察与选题候选放在同一视图：

1. 选择来源范围或素材集合。
2. 运行“灵感漫步”或评论洞察。
3. 审查候选标题、方向、证据和评分。
4. 放弃不合适的候选，保留可执行方向。
5. 点击“AI 创作”把选题和引用带入创作工作台。

生成内容前应核对来源事实、时间和版权。模型输出不是事实保证。

## 5. AI 创作

创作工作台支持多会话、引用、附件、任务时间线和结构化稿件：

- 用 `#` 或界面选择器加入知识来源。
- 明确目标、受众、交付形式和约束。
- 在时间线查看模型与工具调用状态。
- 对文件写入、发布等高影响操作审查确认。
- 把最终结果保存为文章、脚本、小红书图文或其他当前支持的稿件类型。

若收到额度或鉴权错误，打开 AI 设置检查实际使用的供应商、Endpoint、Key 和模型。GardenFlow 不提供积分或统一结算。

## 6. 图片、视频与音频

生成工作台按媒体类型保存独立配置。提交任务前会显示当前供应商、模型和能力约束。

- 图片：提示词、参考图、尺寸、质量和数量。
- 视频：文生视频、图生视频、首尾帧、续写或音频驱动，具体取决于预设能力。
- 音频：语音合成、音色、转录与相关模型能力。
- 封面：模板图、标题层级、风格和生成结果。

结果成功写入真实文件后才进入媒体库。媒体库可以预览、定位文件、复用为参考素材或绑定到结构化稿件槽位。

`new-api-aliyun` 和 `new-api-minimax` 必须在视频设置中显式选择。若 Endpoint、Key 或模型缺失，任务会直接显示可修复错误。

## 7. 自动化

自动化页包含定时任务、内置采集任务和运行记录：

1. 创建任务并选择计划模式。
2. 审查目标、作用空间和需要的工具。
3. 保存后可启停、立即运行或删除。
4. 在通知中心和任务卡查看进度、失败原因与产物。

发布、持久化写入和其他高影响动作仍受审批策略约束。运维人员可用 `GARDENFLOW_HOLD_AUTOMATION=1` 暂停后台调度。

## 8. 数据与隐私

- workspace 与 SQLite 数据默认在本机。
- API Key 只用于请求所选供应商。
- GardenFlow 不包含使用分析或自动诊断上传。
- 桌面诊断和扩展诊断都有数量上限，仅由用户手动导出。
- 导出报告会移除 Cookie、Token、密钥、网页正文、Data URI 和绝对路径；发送前仍应人工复核。

在“设置 → 隐私与诊断”可以打开日志目录或导出本地诊断包。

## 9. 常见问题

### AI 功能不可用

确认路由不是 `disabled`，供应商已启用，Endpoint、模型和 Key 完整；本地服务还要确认进程正在监听。

### 模型列表能加载，但对话失败

模型列表接口与流式对话、工具调用、视觉附件可能不是同一能力。核对协议类型和模型支持范围，并用最小纯文本请求验证。

### 浏览器扩展未连接

确认已加载当前构建目录，在应用中再次执行“准备浏览器插件”，然后重启浏览器与 GardenFlow。可运行插件诊断命令查看 Host 和 Desktop Bridge 状态。

### 媒体任务没有结果

查看任务错误、供应商预设、模型能力和输入文件格式。只有返回真实媒体文件的任务才会登记为成功。

### 如何备份

退出 GardenFlow 后备份当前 `gardenflow.db` 和完整 workspace。详见 [本地开发与部署](./LOCAL_DEPLOYMENT.md)。
