# 作品优先的界面规范

GardenFlow 面向个人及小团队内容运营，围绕「从真实需求中找到方向，制作可发布的作品，再用反馈改进下一轮」组织界面。用户可以从已有资料、一个机会或空白作品开始。

## 导航与页面

桌面端使用单条文字侧栏，展开当前模块的二级入口：

| 模块 | 页面 |
| --- | --- |
| 工作台 | 继续工作、待处理 |
| 研究与选题 | 消费者机会、消费者研究、灵感选题、来源复核 |
| 创作 | 我的作品、成组内容、AI 助手、生成工具 |
| 发布 | 发布任务、发布历史、账号与连接 |
| 复盘 | 作品表现、内容实验 |
| 资源库 | 资料、商品与品牌、角色与声音、媒体、风格档案 |
| 自动化 | 自动任务、运行记录、待确认 |
| 设置 | 通用、AI 服务、连接、技能、成员、隐私与诊断 |

空间位于侧栏顶部，自动化和设置位于下部。全局提供新建、资料搜索、通知和运行记录入口。消费者机会、发布、成组内容和实验可以在两次导航点击内进入。

工作台以最近可用作品和待处理事项为主。作品目录聚合当前空间的创作工程、独立视频、梦境故事及旧稿件，按工程与原生文件关联去重；缺失或损坏记录保留并标注。超过目录读取上限时明确提示部分加载。

消费者研究按「选择资料、核对范围与模型、分析结果」组织，来源不默认全选，模型请求继续单独确认。机会详情保留支持、反例、样本限制与原文定位，已采纳机会可进入单件创作或成组内容。

首次使用的研究、来源复核、成组内容、作品表现、实验、媒体、风格档案及 AI 配置页面提供任务说明和下一步入口。采样设置、评分、CSV 规则、版本标识及其他辅助信息按需展开；没有数据时不展示空白详情表单。自动任务先展示当前任务，内置采集与发布模板可展开选择。

界面使用 IBM Plex Sans / Noto Sans SC，正文与输入为 14px、辅助文字为 12px。文字尺寸使用明确的像素令牌，避免应用根字号使默认 rem 字号再次缩小。共用按钮、输入、引导与辅助操作组件，保留各类作品画布的专用排版。

发布任务、历史及连接状态分别呈现；上传核对与最终提交继续使用独立按钮确认。复盘保留数据来源、指标口径与观测窗口，无法比较时显示不足以判断。导入时可选择发布作品，补充 CSV 中空白的关联，已有逐行关联不变。

## 作品编辑

图文、套图、商品视频、混剪和梦境故事共用作品栏与画布框架。页面或镜头导航放在左侧，作品预览居中，右侧约 320px 的辅助面板切换属性、AI 助手及创作上下文。商品视频时间线位于预览下方。普通文章和脚本保留正文与现有写作检查器。

普通文章仍可手工编辑和保存。AI 修改差异提案属于可选能力；当前主进程未提供相应处理接口，界面不会在打开稿件时请求该能力。

创作上下文汇总消费者机会、实验要求和成组内容任务。切换辅助工具不创建第二份作品；手动编辑、自动保存、撤销、版本冲突与付费操作确认继续由原服务负责。

进入编辑器收起全局侧栏。通过返回入口回到来源页面；作品目录按空间保留搜索、筛选、布局与滚动位置。平台版本仍是独立工程。

## 视觉与响应布局

- 背景 `#F7F8FA`，面板 `#FFFFFF`，正文 `#1F2933`。
- 鸢尾品牌色 `#4B3269` 用于焦点、选中与主要动作；苔绿 `#55746D` 用于辅助提示。
- 使用本地打包的 IBM Plex Sans、Noto Sans SC；正文以 14px 为主，页面标题以 20–24px 为主。
- 标准侧栏约 208px，作品缩略栏约 120px。1440px 编辑器主画布至少占可用区域的 60%。
- 编辑区域不足 1200px 时，属性与 AI 使用抽屉；主导航不足 1040px 时使用覆盖导航。960×680 下避免页面整体横向滚动，视频时间线允许局部滚动。
- 深色模式保持相同结构；动效遵循 `prefers-reduced-motion`。主要点击区域至少 36px，键盘焦点可见，弹窗支持 Esc 与焦点返回。

## 插件与维护

采集插件按当前页面、保存空间、采集范围与结果组织；队列及日志按需展开。发布插件展示真实平台连接及页面就绪状态，提供打开桌面任务入口。浏览器交接仅允许打开资料、商品或发布页面，不能代替生成、上传或提交确认；桌面空间变化时拒绝打开原空间对象。

主题从品牌源配置生成，桌面端与两个插件使用同一组语义令牌。路由采用类型化 `AppRoute` 与 `route.open`，兼容原有导航意图。纯界面状态不新增业务表，也不根据用户消息关键词决定 AI 路由。

运行记录目前显示每个自动任务最近一次执行；完整过程进入关联会话查看。风格档案支持手工管理样本，自动账号学习尚未接入当前桌面端。
