# 消费者机会与创作依据

[文档首页](./README.md) · [创作工作台](./CREATION_WORKBENCH.md)

在「灵感 → 消费者机会」中，把当前空间已有商品评论或知识原文绑定到一个内容方向，采纳后创建现有创作工程。可手动整理，也可明确确认后调用设置中的灵感文本模型。

## 从资料分析候选机会

点击「消费者研究」，选择当前空间的来源、评论上限与可选研究目标，再点击「预览本轮范围与模型」。预览显示保存条数、本轮实际样本、发送片段与字符数、部分采集限制及模型主机。字符数不是计费 Token 数。不会默认选择全部资料。

预览会逐项列出本轮已冻结的来源名称、版本、采集时间及实际发送数量；可展开「查看本轮将发送的原文」检查内容。从运行记录查看历史范围时，仍显示当时的来源版本。

勾选发送原文与可能费用的确认项，再点击「确认并运行分析」，才发起一次文本请求。来源或模型配置发生变化时需重新预览。同一数据、范围和模型的已有结果会复用；失败、取消或重启中断后不会自动补发请求，重试需重新选择范围并确认。采样先保留每个来源的一段背景，再按来源轮流选取评论，最后补充其余资料；超出片段或文字上限会明确提示。

模型只生成候选、反例、缺口和带理由的主观评分。程序在本轮冻结的原文中核对引用；虚构 ID、改写的引文，以及把商品规格当成消费者评论的引用不能通过核验。建议优先级只用于排序，不能解释为成功概率。样本不足时会降低置信提示；没有可信机会时允许返回 0 项。

可按来源、状态及建议优先级查看机会。运行记录保留最近 50 项入口，可取消正在进行的分析；取消后不写入迟到结果。现有手动机会和创作流程可独立使用。单次文本分析已验证百炼 `qwen3.7-plus`；其他供应商与模型组合仍需逐项验证。小样本结果可能仅部分成功，缺失资料会保留在机会中。

## 手动绑定依据

1. 点击「手动新建机会」，填写标题、问题、受众和创作角度。
2. 选择已入库来源及原文片段，粘贴其中连续的一段原文，选择支持、反例或背景，点击「绑定这条原文」。可绑定多条证据。
3. 保存机会。没有支持证据时明确标为待验证假设；这不代表已经开展消费者研究。
4. 查看证据，点击「打开原始来源与定位」核对历史版本及完整片段。来源更新或删除后会显示对应状态，不会把旧引用自动改指新版本。
5. 点击「采纳」，选择平台与创作形式，再点击「确认目标并基于此创作」。商品视频、混剪和套图需要来自机会证据的明确商品；多商品机会需要先缩小范围。
6. 在创作工作台展开「创作依据」，回看机会、支持与反例。已有无关联作品仍可直接编辑。

新建工程只保存本地草稿和创作会话。图片、视频、配音生成及上传、最终发布继续使用原有确认流程。请求失败后可在当前面板重试；相同请求会恢复原工程与关联。源资料过期且尚未建工程时，需要重新复核。

「可定位原文」表示引用与该来源版本吻合，不表示评论主张或商品性能已经得到独立证实。采集条数是本次样本数，不能当作全平台消费者比例。部分采集、缺少评论和不完整资料会明确显示；单来源超过 800 条去重评论时，只纳入前 800 条并显示限制。文档知识预览最多包含 12000 字，证据只校验可见原文。

当前来源包括商品采集快照、用户确认的商品事实、可识别平台的本地社媒资料，以及文档知识预览。不会自动补采、修改商品资料、重新生成媒体或发布。超过 20 个来源或创作摘要过长时，需要缩小机会范围。

## 来源变化与内容维护

在同一页面点击「来源复核」，选择曾保存并引用的来源版本，再点击「检查当前入库版本」。程序比较当前空间的本地资料，显示旧新快照、规格和原文字段的变化，并列出引用旧版本的证据、机会、直接关联工程及其派生工程。相同商品但没有旧版本引用链的工程单独计数，不当作已确认受影响。检查不访问平台补采，也不调用模型。

每轮清单冻结当时的来源和工程版本。相同来源与影响范围重复检查会复用；工程内容、来源或引用关系变化后，再次明确检查会建立新一轮，旧决定不会覆盖新内容。旧引用始终保留原版本，即使新版本中同一定位的文字相同，也需要核对适用范围。当前来源缺失、某字段本次未采集，都不等于平台已删除内容；价格须连同 SKU、币种和条件核实。

选择一个影响项，查看原始证据或打开原工程，然后选择「保留历史依据」「计划补充证据」或「计划手动修改」，填写理由并勾选确认，才会记录本项决定。已记录决定不代表稿件已修改、证据已补齐或已发布更正；后续编辑与发布仍走原流程。每项可查看最近 100 次处理记录，页面保留最近 50 轮复核入口。

扫描范围为当前空间注册的创作工程及内容机会直接关联。未注册的旧工程不在范围内；损坏、空间不符或无法安全读取的索引会计入排除数，并明确标为扫描不完整。超过 5000 条索引或 2000 个关联对象时停止检查，不截断为完整清单。检查和人工决定在本地持久保存，不自动改稿、生成媒体或发布。
