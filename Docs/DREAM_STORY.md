# 梦境故事

[文档首页](./README.md) · [模型配置](./AI_PROVIDERS.md) · [测试](./TESTING.md)

梦境故事把个人记录做成可继续编辑的八幕故事短片。入口位于首页「记下一个梦」及「创作」中的「梦境故事」，作品保存在当前空间。开发版接入 TikTok Studio；真实供应商生成和账号发布需要逐次核对，离线测试不代表真实发布验收。

## 从记录到作品

1. 输入记得的片段。可以只写一个字并保存，保存记录不调用模型。「记录与版本」中可补充日期、情绪和偏好，或锁定原句。
2. 确认 TikTok Studio 目标与制作模式。新工程默认混合模式、英文、`International`、72 秒、有声旁白及字幕；目标可选 60–90 秒，画布固定为 9:16、1080×1920、30fps。声音 ID 应与所配置的语音供应商兼容。
3. 打开「梦境导演」请求故事和八幕分镜。文本调用可能收费；原始片段和 AI 补写分开保留。核对候选后，依次采用草案、故事和分镜。
4. 修改画面、旁白、提示词、时长和顺序。锁定分镜需要先明确解锁；「故事」中可调整画风及角色设定。文字修改自动保存，导演对话发送前也会保存当前输入。
5. 先试一幕，再确认所选幕的生成批次。批次展示供应商、模型、数量、参考图、声音和请求上限；无法核实价格时显示费用未知。可导入图片、逐幕配音和本地 BGM，无需配置视频生成服务。配音完成后可在分镜卡片内试听，播放器下方显示实测秒数；旁白变化时会提示声音已过期。
6. 逐幕确认关键帧，再生成低清预览和正式 MP4。配音使用实测时长，自动字幕将长句拆成短段，在画面下方安全区显示；可人工调整文字和时间。缺少旁白时应导入或生成声音，也可以明确关闭旁白；不会静默降级为无声成片。

图片和语音各最多并发两幕，渲染串行执行。成功素材保留，单幕失败可建立新的重试批次。「停止未提交幕」不会撤回已发生的供应商调用或费用。

## 连续画面与制作模式

- 全图片：八幕图片加运镜，不调用视频模型。
- 全视频：先确认八幕关键帧，再逐幕生成或导入真实视频；关键帧与视频分别核对调用。
- 混合：导演首次推荐两幕视频并说明理由，其余为图片运镜。采用后可手动调整各幕媒体类型，再采用分镜。

在「人物与场景基准」中按对象导入参考，或采用已确认画面。先试一幕并确认，再作为固定基准沿用；重复出现的人物或场景未指定固定基准时，后续生成会暂停；新增生成仍须核对批次。连续镜头还使用上一幕已确认画面，不能在同批次中预授权尚未产生的前序参考。切换场景时选择「切场」，保留人物和画风基准，不继承旧背景。分镜卡可比较当前图、前幕及参考。参考约束不能保证人物绝对一致；不支持所需参考数量的模型会阻止调用。

同一张源图可分别为人物和场景设置「裁切此参考」，只在本地裁切，不调用模型。人物裁切保留头部和服装，场景裁切可避开人物和临时道具。调用卡展示实际裁切图；授权同时绑定源文件与裁切文件哈希。改变裁切会使依赖它的后续画面过期，已有文件保留。过期图片可点「复用此图片，重新核对（不生成）」沿用原文件，再单独确认；这不调用模型，也不声称素材按新参考重新生成。裁切区域须在原图内且至少32×32像素。

在每幕「机位与空间约束」中可选择沿用布局或换机位，并填写关键物件的数量、原位置和当前状态。例如原场景只有一张监考椅时，描述主角坐在原椅上，避免原椅空着又多出第二张。换机位仍保留物件位置；这些约束需要在生成后逐幕核对，不能保证模型一定遵守。

参考图用于延续身份、服装和场景空间，当前幕的动作与构图优先。核对时同时检查人物一致性与剧情是否推进；如果只是复制前幕姿势，应调整当前幕提示后重新核对调用，不采用该图推进连续链。道具设定是跨幕清单，只应出现当前幕需要的道具。

每幕「提示词、角色与字幕检查」可选择「仅上一幕图片」，仅用于延续镜头：把上一幕已确认整图与当前幕文字一起生成，固定人物／场景基准保留在工程中供核对、本次不发送。默认仍使用固定基准加前序画面；单图沿用可能逐幕漂移，切场不能选择此方式。

「精简单幕」是显式选项，用本幕画面和人工整理的提示词替代全量画风、角色与场景文字；请在提示词写明所需人物、服装、地点和画风。机位、空间约束和实际参考用途仍附加，不自动删减现有提示。默认「完整上下文」保持原组装方式。改变任一方式会使相关媒体待重新核对，不触发模型。

图片调用卡可展开查看本次实际发送的完整指令。已知 Qwen 模型采用本地保守估算并预留20%分词差异余量；超出安全预算会禁用生成，主进程也会阻止提交，不自动删减原文。估算不是供应商精确分词或计费依据。梦境调用对支持的模型关闭供应商智能提示改写，商品等既有调用未指定该设置时保持原行为。Qwen 2.0 的已知上限为1300 Token，超出由服务端截断，参见[官方接口说明](https://help.aliyun.com/zh/model-studio/qwen-image-edit-api)。

视频幕先完成关键帧和当前旁白，再按计划与实测音频选择能覆盖整幕的最短支持时长。确认卡展示模型、参考、生成秒数、清晰度和请求上限；超出单次时长上限时需调整或重新规划，不自动拆段。视频任务串行，原声关闭或在合成时静音，旁白和字幕继续独立制作。超出分镜的尾部会裁去；不足时不会停帧、循环或慢放补足，也不会静默退回图片。

生成完成后试听并确认视频，才能导出。失败或未知结果不自动重投。编辑期间返回的旧结果保留为候选，选择后仍需按当前内容重新核对。

## 版本与变更

采用故事和分镜时保存版本；恢复历史版本创建新的当前修订，保留已生成文件。旧候选不覆盖新的手动输入。修改某幕旁白只使相关声音、字幕和成片过期；修改画面或角色设定需要重新核对受影响图片。

语言和市场变化创建独立作品版本，原工程保持原样。新版本不继承生成或发布授权，既有媒体需要重新核对。

重启会读取工程和项目内媒体任务记录，核对已落盘结果。中断或结果未知时先检查供应商，再明确建立重试批次；恢复不会自动重投付费请求。

请求已经提交但缺少可信完成回执时，画面显示结果未知，不能据此判断供应商失败或未计费。提示规则升级后，旧的未执行图片核对卡需要重新预览；已有确认素材继续保留。

## 导出与导入

- 支持故事 Markdown、分享用导演包 JSON、SRT、MP4 副本和 ZIP 素材包。
- 分享默认排除原始记录、历史版本、内部提示词及仅用作参考的原图。归档选项可明确包含私密创作内容；完整备份另保存工程快照和媒体清单，并始终包含全部素材（含参考原图）；勾选私密内容时还包含原始记录和历史。
- 旧导演包导入支持独立项目的 `schema_version: "1.0"`，以及详情 JSON 中的 `package`。先展示语言、原始记录有无及缺失项，再创建新作品；源文件保持原样。
- 旧图片和配音需手动导入并按幕匹配；缺少目标时必须先确认并适配。原文件没有原始梦境时不会反推，也不会恢复旧供应商任务。

新梦境工程格式版本为 4，旧格式3继续采用全图片方式，商品工程保持原格式。旧作品启用连续性或视频模式时，通过「创建新版连续性副本」创建独立作品，再由导演适配并采用新版分镜；原工程、成片及已发布记录保留。制作模式、语言或市场变化也创建独立副本。较早应用无法读取格式4，请使用支持该功能的版本。ZIP 是可移植快照；当前导入入口只接受上述旧导演包 JSON，不提供 ZIP 一键恢复。

## TikTok Studio 发布

保存描述、话题及全部发布设置，再点击「准备发布到 TikTok Studio」。未连接插件不影响本地创作和导出；准备发布时需要真实账号与新版发布插件。

准备阶段不上传。先点击「上传到页面供核对」，回读账号、成片、文案和设置，再单独点击最终确认发布。生成来源会提示 AI 标记，实际选择仍需使用者核对。发布面板列出正式成片的八幕封面候选时间点，可点击预览；首版由使用者在 Studio 中确认实际封面。

首次开启 AI 标记时，Studio 可能显示说明弹窗。确认开启后，回到 GardenFlow 继续同一任务的页面核对；无需新建任务或替换已上传的视频。发布前检查实际封面，避免选中开场淡入的黑帧。

保存 Studio 封面会使旧的上传核对失效。如果只修改了封面，可在发布面板勾选「我仅在 Studio 修改了封面，未替换视频或修改文案、设置」，点击「重新核对封面（不上传）」，再最终确认。此操作复核原任务、文件名、上传状态、账号、文案和设置，不重新上传视频；无法核实视频未替换时不要勾选。复核后再次改动封面仍会阻止提交。

账号、浏览器、页面、文案、设置或媒体变化会要求重新核对。结果未知或待审核时不会自动重发；可信作品链接未取得时保持缺失。

如果提交后显示「结果未知」，先在原账号的 Posts 中核对对应视频、文案、时长和可见范围。确认已发布后，在 GardenFlow 勾选人工核实并点击「记录已发布」。按照提示将原标签返回空白视频上传页，再完成记录；页面恢复不上传或发布视频。最后返回 Posts，点击「读取作品回执」。只有账号、完整文案、可见范围、时长和发布日期唯一匹配时，面板才保存可信作品链接。审核中不能按已发布记录，也不要重新提交。

保存后的任务和回执可从「计划 → 发布 → 查看任务与回执」重开，无需重新准备或上传作品。

## 私密内容

原始梦境默认只进入当前工程的创作上下文，不参与全局记忆或普通推荐。媒体生成只发送所需画面设定、参考图或旁白；全局媒体条目不保存私密提示词，任务正文留在项目范围内。显式导出、分享及发布的内容由使用者核对。

本地文件沿用应用的存储方式，不代表已加密。导出副本及供应商留存不会随本地编辑自动改变。
