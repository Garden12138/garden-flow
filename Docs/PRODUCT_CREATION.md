# 商品创作与发布

[文档首页](./README.md) · [使用手册](./USER_MANUAL.md) · [路线图](../ROADMAP.md)

从已入库的商品制作视频或小红书套图，在独立工程中持续修改、导出，再逐步确认发布。本文描述当前源码能力；较早安装包可能没有全部入口。

## 选择商品和目标

1. 在“资产库 → 商品”核对商品、规格、来源和图片。
2. 在创作页用 `@` 选择该商品，点击“商品创作”；套图或混剪快捷入口会预选对应形式。
3. 选择平台、内容形式、视频编排模式、语言／市场及规格，填写创作要求后点击“按此目标规划”。取消选择不会请求模型或创建工程。
4. 核对方案卡中的商品规格、真实素材缩略图、逐镜头／逐页文字、布局和发布文案，再确认创建。

![选择商品创作目标](../images/product-creation-target.png)

截图来自实际演示工程，背景文字用于功能测试。用户选择的目标会保存到工程，模型不能改换平台或规格。待确认期间商品被更新或删除，旧方案会失效；已创建工程保存独立素材和商品快照，后续源商品变化不会改写它。

| 平台与形式 | 默认规格 | 支持范围 |
| --- | --- | --- |
| 小红书视频 | 9:16、1080×1920、30fps、15 秒；可选 16:9 | 创作、编辑、MP4 导出及发布 |
| 抖音视频 | 9:16、1080×1920、30fps、15 秒 | 创作、编辑、MP4 导出及发布 |
| TikTok 视频 | 9:16、1080×1920、30fps、15 秒 | 创作、编辑、MP4 导出及发布 |
| 小红书套图 | 3:4、1440×1920 PNG，5 张含封面 | 创作、编辑、PNG／目录／ZIP 导出及发布 |
| 抖音／TikTok 套图 | 待适配 | 暂不可创建 |

TikTok 默认英文、目标市场 `International`，创作前可修改；小红书和抖音默认中文。视频最多 8 个镜头，每镜头最多 30 秒，这是应用支持限制。字幕安全区是排版建议，仍需在平台预览核对。

默认使用商品原图编排或用户选定的已有视频片段，不自动提交图片、视频或语音生成。规划、视觉理解及对话编辑会使用所配置文本模型，供应商可能收费。需要生成媒体时，另行核对模型、参考素材和计费提示并确认；不支持参考图的模型会阻断该生成请求。

## 持续编辑

工程工作台支持手动编辑和工程专用对话。原创作会话的“继续编辑此作品”进入同一编辑对话；每个平台版本独立保存会话，关闭重开后继续使用。

发送编辑消息前自动保存当前手动输入。保存失败或版本冲突时保留输入并停止模型请求；模型等待期间有新编辑时，旧结果不会覆盖它，可按最新工程重试。普通可撤销修改会直接应用并展示实际变更，最近 20 次编辑可撤销；手动修改和对话修改共用历史。

可以直接要求“缩短第二个镜头”“把第三页改成多图细节”“修改发布标题和话题”。素材替换请用素材选择器或明确素材 ID；没有画面依据时，需要先选择素材或补充说明。发布可见范围等设置继续在对应平台面板中选择。

### 视频与已有片段混剪

可改字幕、旁白文字、镜头时长与顺序，删除镜头、替换素材、修改截取区间、适配画幅和原图动效，以及调整来源原音、旁白和背景音乐音量。

混剪先选择属于当前空间的已有片段，再核对每段截取区间。原音与旁白、音乐分开控制；是否静音以实际音轨设置为准。旁白超出镜头时长时需延长镜头或调整文案。

修改旁白文字会使旧配音过期，不自动重新生成。导出时若仍绑定过期配音，需要明确重新生成或移除；没有配音素材的工程可静音导出。

### 小红书套图

![小红书商品套图编辑工作台](../images/product-image-set-workbench.png)

该截图来自实际验收工程，商品与文字用于流程演示。封面画面与标题分别编辑；画面生成不会把文字变成不可编辑的图片。

提供封面大图、图文分栏、多图细节三种模板，可改文字、替换图片、裁切、配色和字号。封面固定第一张，内容页可增删和排序，最多 20 张。默认使用商品原图；按页选择 AI 画面时，每次生成一张，失败可单页重试。

页面修改后，旧 PNG 标为过期；整套导出只重渲染受影响页面。长文字溢出或素材损坏会提示具体页面。迟到的过期生成结果保留为素材，不覆盖当前页面；重启不会自动重投中断的付费请求。

## 导出与其他平台版本

视频导出 MP4 并保存到资产库。套图支持单页 PNG、整套目录和 ZIP；ZIP 按封面及页面顺序包含最终图片、文案和清单。缺页或过期页面不能算整套完成。相同内容重复导出会复用已有产物。

画面或声音修改需要更新对应导出。仅发布文案或设置变化可复用媒体，但旧发布确认仍会失效；撤销不会恢复旧提交授权。

工程确认后不能原地切换平台。通过“创建其他平台版本”复制独立素材和工程，按新目标适配画幅及文案；默认打开已有目标版本，只有“再复制一版”才新增。修改副本不会改写来源工程。TikTok 的“AI 语言建议”先展示对照，确认应用后才写入；旁白变化仍需处理过期声音。

旧工程可继续普通编辑和导出。如果平台关系不明确，发布准备会要求先明确绑定目标。

## 准备、上传与最终发布

在当前工程点击“准备发布”，或从“计划 → 发布”查看连接、账号、浏览器、待处理任务和历史。需要已保存的当前工程、有效的最新媒体、明确的平台绑定和完整设置；准备失败会保留输入，不自动重新渲染或生成媒体。

发布分为两个独立按钮确认：

1. **准备发布**：创建本地任务，读取真实账号和页面状态，展示媒体、文案和设置，不上传。
2. **上传到页面供核对**：检查当前工程、账号、浏览器和页面草稿，上传并回读媒体、文案及设置。完成后等待最终确认。
3. **最终发布**：再次核对同一任务、账号和上传结果，通过按钮明确提交。

在对话中回复“发布”只会引导打开确认卡，不执行上传或提交。工程编辑、换账号、换浏览器或手动改变页面内容会使旧确认失效。插件不会覆盖、删除不属于当前任务的页面草稿；请先人工核对原草稿。

小红书套图发布最多 **18 张，这是应用限制**。19／20 张工程仍可编辑和导出，需要用户减少页数后再准备发布；不会自动截断或拆成多篇。封面始终第一张，其余按页面顺序上传，相同图片也保留各自位置。

TikTok 的可见范围、评论、内容复用、Remix、商业披露、AI 标记及年龄限制必须由用户完整选择。账号无法可靠识别、插件缺少核验能力或页面状态不支持时会阻断。

上传失败可重新核验后重试。提交结果未知、审核中或已经提交的任务先核实状态，不自动重发；可信作品链接未取得时明确保留缺失。编辑与重启不会改写已提交或已发布任务的原快照。TikTok 真实审核／拒绝分支的验证范围见[路线图](../ROADMAP.md)。

## 完成后询问是否发布

“计划 → 发布”提供小红书、抖音和 TikTok 三个独立开关，抖音／TikTok 默认关闭。未连接插件时也可开启询问，实际准备和发布仍需账号、插件及页面就绪。

最新完整 MP4 或整套图片目录／ZIP 成功导出后，询问进入该工程版本的编辑对话。单页 PNG、部分完成、失败导出和普通保存不触发。相同内容重复导出或重启不重复询问；选择“暂不发布”后同一内容不再询问，仍可手动准备发布。新内容再次成功导出可产生新询问。

开关只作用于之后的完成事件，不补发历史作品。关闭开关会取消尚未进入提交阶段的自动询问和自动来源任务，手动任务保持独立；已进入提交阶段的任务继续观察结果。询问本身不调用模型、不上传、不提交。
