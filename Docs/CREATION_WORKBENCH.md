# 三栏创作工作台

[文档首页](./README.md) · [商品创作](./PRODUCT_CREATION.md) · [梦境故事](./DREAM_STORY.md)

选择平台和创作方式后即可打开空白作品。工作台统一分为「创作对话」「作品编辑」「效果预览」，支持小红书图文与视频、商品套图、各平台商品视频及已有视频混剪、TikTok 梦境故事。

## 开始创作

- 在创作对话中描述想法，AI 通过结构化工具保存文案、页面和分镜，结果同步到作品编辑与预览。
- 也可直接在作品编辑中填写内容。未完成的输入可以保存；商品和来源素材可稍后选择。商品方案填写完整后点击「继续制作」，校验并创建可编辑作品，这一步不提交付费媒体任务。
- 梦境故事可以从对话中的原始梦境开始，也可以展开「手动编写故事与八幕分镜」，逐步保存未完成的故事与分镜。

手动编辑通常在停止输入约 600ms 后保存。发送消息、切换作品或进入生成与发布前会先保存输入。保存失败时保留草稿；若 AI 返回期间已有新的手动输入，过期修改不会覆盖当前内容。

## 图文卡片

小红书图文笔记提供自由创作、文章转卡片、知识图解和步骤教程。展开「创作方式」可以设置文章来源、内容表达、读者与要求；文章来源可与图解或教程组合，切换表达方式不会解除来源绑定。

来源支持 Markdown、TXT、文本型 PDF、DOCX、知识文档、已收藏文章和文本稿件。附件先保存到当前空间，原文件移除后仍可读取快照。原文更新时提示版本变化，点击「重新读取」添加新版本，不自动改写已有页面。空内容、损坏或不支持的来源可以重试或更换；扫描 PDF 需要先自行 OCR，旧版 `.doc` 请先转成 DOCX。

卡片包含封面、标题正文、图文分栏、对比、步骤及总结清单六类模板。正文、重点词、图片裁切、对比项和步骤均可编辑；知识图解目前支持线性流程、对比与清单。已有内容更换创作方式时，可只调整后续方向，也可调用文本模型生成重组候选，查看页面与字段差异后应用，之后可整体撤销。

不配置模型也可以添加页面、手动填写和导出。默认输出为 3:4、1440×1920，支持当前页 PNG、整套目录和 ZIP；套装附带发布文案和作品清单。导出检查溢出和素材引用，失败页可单独重试。有效页面图片可复用，旧导出保留供查看；普通卡片暂不提供自动发布，请手动上传。

「生成初稿」与聊天使用文本模型；「生成配图」使用单独确认的图片模型请求，生成的配图与可编辑文字分开保存。旧图文页面保持原 ID 与素材，选择模板后转换为结构化卡片；没有图片也未应用模板的旧页面仍标为图文方案。

## 预览与媒体

作品编辑和预览共用当前作品状态。图文展示排版与发布文案，商品套图展示当前页面，商品视频展示本地时间线，梦境故事展示分镜及已有媒体。已渲染的视频与本地编排预览有所区别：修改脚本不会自动重新生成视频、图片或配音，过期媒体需重新核对。

普通文字与编排修改直接保存并可撤销。图片、视频、配音生成及发布保留各自的确认步骤。历史候选仍可查看，已经过期的结果需要基于最新作品重新处理。

## 布局、历史与版本

工作区充足时三栏并排，可以拖动分隔线调整宽度，或收起对话和预览。工作区不足 1000px 时保留对话，使用「查看预览／返回编辑」切换中间区域。

进入创作时应用历史侧栏默认收起，可随时展开查看最近对话；退出时恢复原状态。新作品从空白草稿到制作阶段沿用同一段对话，重新打开可恢复作品与原消息。旧作品保留已有编辑对话和原创作记录，不合并旧消息。

顶部「另建版本」保留原作品与对话。同类型商品视频复用已有平台适配流程，梦境故事复用目标副本流程；跨类型只带入可复用的需求与文案，缺少的素材和专用字段需要补充。新版本可以返回来源作品，也不会继承新的付费生成或发布授权。
