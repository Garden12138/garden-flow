| --- | --- |

## 脱敏与回放

保留实际节点层次、CSS 模块类名、规格选择、价格显示、参数和评论配对结构。商品／SKU／属性 ID、标题、买家昵称、日期、购买规格、正文、回复及图片 URL 已替换；账号、收货信息、跟踪参数、表单、事件属性和外部脚本已移除。缩减后的 ICE JSON 仅保留解析所需的当前商品身份和属性表，不执行。

Chrome 改写的本地图片路径保留为 `saved_files/`，用于验证本地文件不被当作远程下载来源。懒加载占位图不说明实际图片已取得，标签计数也不能补出没有保存的评论。2026-10-06 夹具没有完整评价弹窗，离线回放应保留已读两条并提示列表未加载。

## 运行与边界

```sh
pnpm --dir Plugin test:taobao-product
```

测试覆盖当前页面选择、价格与 SKU 身份匹配、图片源去重、参数提取、初评／追评及商家回复配对，以及本地路径拒绝。动态弹窗、标签切换、加载超时、登录／验证／限流、懒加载与乱码回退使用合成变体。

修改夹具时保留来源类别与脱敏边界，不把合成事件写成真实站点行为。离线解析不验证真实页面加载、图片下载或桌面入库；这些需要独立的应用验证。公开测试方法见[测试文档](../../../../Docs/TESTING.md)。
