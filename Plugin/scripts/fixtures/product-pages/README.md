脱敏夹具保留商品标题、店铺名、商品图、价格、规格选择、参数表、图文详情和当前两条评论的 DOM 结构与类名前缀。商品／SKU ID、商品标题、店铺／品牌名称、买家昵称、评论正文及图片 URL 已替换；去除账户导航、收货地区、个人优惠、跟踪参数、表单及其他脚本。唯一保留的脚本是缩减后的 ICE JSON 初始化结构，仅包含当前商品身份、5 张商品图和 SKU 属性对应表，不执行该脚本。

Chrome 保存网页后改写的本地 `src` 形式在夹具中保留为 `saved_files/`，用于验证只读取该商品已声明的合法远程图片源，不将本地文件路径当作下载地址。详情图的 `data-src` 结构保持不变。5 张商品图与 9 张详情图有 1 张重叠，去重后应为 13 张；参数应为 26 项；当前选中黑色、2XL，页面高亮价格为 ¥95，优惠前 ¥122 不作为当前价。脚本中的其他规格不得作为当前选择。

运行 `pnpm --dir Plugin test:taobao-product` 可验证结构提取。测试另外构造了价格隐藏、SKU 变更、错误身份、正文折叠及标签打开弹窗的变体；这些变体属于合成回归，不是新的实页证据。原始保存页只有 2 条内嵌评论和“查看全部评价”入口，没有完整列表的 DOM、商家回复和评论图。插件应先点击该入口；纯离线保存页没有点击响应，因此回放只能保留这 2 条并明确提示完整列表未加载，不能根据“用户评价 200+”或标签计数推断更多评论。
