# 设计

- 独立 `tiktok_video_versions`、`tiktok_publish_jobs`、`tiktok_publisher_config` 表使用空间、工程和版本索引；保留旧抖音／小红书表和协议。
- 版本服务复制现有商品工程；文案保存采用版本 compare-and-swap。语言建议由主进程保留并绑定版本／工程时间；逐镜头修改在工程的 mutation queue 内验证后一次写入，原素材与源工程不变。
- AI 使用用户当前文本模型／协议，输入为事实快照与镜头文字，输出只接受完整镜头 ID 集合和有界文本。展示后应用；不按用户消息关键词判断发布意图。
- 新增桌面 IPC／bridge 及工作台 TikTok 面板；复用现有镜头、旁白和 MP4 导出入口。
- 发布插件增加 `tiktok.publish.v1`，只声明 TikTok 精确主机权限，prepare/submit 分开。账号来自可见 Profile 链接，上传控件及编辑器来自实际页面结构；不读 Cookie、隐藏用户状态或内部接口。
- 发布摘要覆盖语言、市场、可见范围、内容标记、文案、工程版本与成片。确认／上传／提交前再次验证；未知提交结果持久化且拒绝重投。
- `read-receipt` 只读取已核实发布任务的 Studio Posts 行，插件核对登录账号及唯一匹配，主进程复核 URL、原任务、空间、文案、可见范围、时长和既有回执；回执是可选字段，兼容旧任务。原任务人工核实记录保持独立，不以同文案旧作品自动归因未知提交。
- 语言翻译对已验证支持非思考模式的 DashScope Qwen3.8 Max／Flash 请求设置 `enable_thinking: false`，只影响此次建议请求；其他协议／提供商不传该参数。请求与响应体统一 180 秒上限，超时提示保留稿件，可重试或选择更快模型。能力限定参考官方模型文档，不根据用户消息做模型路由。
- 原页结构核对与合成状态机回归分别记录。仅上传测试片段不算真实商品视频发布验收。
